#### 2. **四面墙场景搭建法**（高级技巧）
**核心思路**：将完整场景拆成东南西北4面墙，逐一生成，最后拼接

**生成步骤**：

   ```

2. **分墙生成**：
   - 墙1：东墙（主景观窗墙）
   - 墙2：南墙（电视主背景墙）  
   - 墙3：西墙（楼梯玄关过渡墙）
   - 墙4：北墙（餐厅联动酒柜墙）

3. **关键技巧**：
   - **比例统一**：所有墙用16:9横版比例
   - **种子值固定**：记录第一面墙的Seed值，后续使用相同Seed
   - **参考图滚雪球**：每生成一面墙，就把它作为下一面墙的参考图
   - **地面衔接**：确保地板纹理方向一致
