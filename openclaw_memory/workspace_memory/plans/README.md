## 📝 使用说明

### 1. 计划管理流程
```
制定计划 → 放入本文件 → 设置提醒日期
     ↓
提醒到期 → 海哥决定：
     ├→ 开始学习 → 添加到 memory/indexes/learning_progress.md
     ├→ 继续延后 → 更新提醒日期
     └→ 删除 → 移到已完成或直接删除
```

### 2. 与学习进度的关联
- **计划**（本文件）：要学什么、何时学
- **进度**（`memory/indexes/learning_progress.md`）：学到哪了、状态如何
- **资料**（`knowledge/`）：学什么内容

### 3. 开始学习时的操作
1. 从本文件中选择一个计划
2. 在 `memory/indexes/learning_progress.md` 中创建新学习项目
3. 链接到本文件的计划项
4. 链接到 `knowledge/` 中的学习资料
5. 更新本文件中的状态为"进行中"
