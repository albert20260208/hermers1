assistant: **Git LFS** 全称是 **Git Large File Storage**（Git大文件存储），是GitHub官方提供的一个扩展工具，专门用来处理版本控制中的大文件问题。

## 🎯 LFS 是什么？

**简单说**：LFS 是 Git 的"外挂"，让 Git 能正确处理大文件，而不会因为单个文件太大导致推送失败。

**核心原理**：
- 把大文件（如图片、视频、二进制文件等）**存储在单独的服务端**
- Git仓库里只保存这些大文件的**指针**（一个几十字节的文本文件）
- 当你克隆或拉取时，Git LFS 会自动下载真正的大文件内容

## 🔧 解决什么问题？

你遇到的正是典型场景：
- 文件 `abi3.so` 超过 100MB
- GitHub 默认限制每个文件 ≤ 100MB
- 直接 `git push` 会报错

**LFS 的解决方案**：
1. 安装 git-lfs
2. 告诉 Git：".so 文件请用 LFS 处理"
3. 重新提交时，.so 文件会被上传到 LFS 服务器
4. 仓库里只剩下一个很小的指针文件

## 📊 对比传统 Git

| 方式 | 仓库大小 | 推送速度 | GitHub限制 | 适用场景 |
|------|----------|----------|------------|----------|
| **普通 Git** | 包含完整文件 | 慢（传大文件） | 100MB/文件 | 代码、文档 |
| **Git LFS** | 仅指针文件 | 快（只传指针） | 无文件大小限制 | 图片、视频、二进制文件 |
