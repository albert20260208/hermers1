# 2026-02-15 研究报告：Seedance 视频制作问题分析与改进方案

## 一、今天视频制作中遇到的问题

### 1. 人物一致性问题
- **问题**：每一幕单独生成，人物脸型、身材会发生变化
- **原因**：没有固定参考图，或参考图使用不一致
- **解决**：先生成人物脸部特写图片，作为所有幕的统一参考

### 2. 场景元素丢失
- **问题**：提示词写了"行人穿梭、商贩叫卖、城楼飞檐"，但生成结果没有
- **原因**：只用脸部特写作为参考图，没有用场景图
- **解决**：场景复杂时，优先用场景图作为参考，在提示词中强调人物特征

### 3. 人物比例失调
- **问题**：主角与周围行人身高比例不协调
- **原因**：提示词中没有明确写人物比例关系
- **解决**：多人场景必须写"身高与周边行人一致，正常人体比例"

### 4. 提示词随意修改
- **问题**：每次修改时改动了原有提示词，导致效果不一致
- **原因**：没有遵循"只增不改"原则
- **解决**：严格遵循"只增不改"，后续修改只在原有基础上增加

### 5. 服装细节丢失
- **问题**：指定了款式1襦裙，但生成结果服装不一致
- **原因**：提示词中服装描述不够详细
- **解决**：服装必须写明类型、颜色、细节、配饰

### 6. API限制问题
- **问题**：Seedance只能用一张参考图
- **影响**：无法同时参考脸部和场景
- **解决**：根据优先级选择参考图，另一个用提示词详细描述

## 二、改进后的标准流程

### 阶段1：素材准备
1. **人物设定图**
   - 生成正面脸部特写（Seedream文生图）
   - 生成侧面脸部特写
   - 生成全身服装图（每套服装）

2. **场景设定图**
   - 生成每个场景的背景图（Seedream文生图）
   - 确保场景元素完整

3. **服装设定图**
   - 每套服装单独生成设计图
   - 记录服装详细描述

### 阶段2：提示词模板
```
[人物特征]
- 发色、发型、发饰
- 面部特征（大眼睛、精致五官等）
- 身材描述（年轻少女身材）

[服装特点]
- 服装类型和颜色
- 服装细节（交领、百褶等）
- 配饰（腰带、玉佩等）

[场景环境]
- 建筑特征
- 环境元素
- 氛围色调

[人物比例]（多人场景必写）
- 身高与周边行人一致
- 正常人体比例
- 人物之间身高比例协调一致

[运镜方式]
- 镜头类型
- 镜头运动
- 特效

[参数]
--resolution 1080p --duration 5
```

### 阶段3：生成顺序
1. 先用场景图作为参考，生成一版
2. 检查人物是否一致
3. 如不一致，改用脸部特写作为参考，在提示词中详细描述场景
4. 每次修改只增加内容，不改动原有提示词

### 阶段4：质量检查清单
- [ ] 人物脸型是否一致
- [ ] 服装是否符合设定
- [ ] 场景元素是否完整
- [ ] 人物比例是否协调
- [ ] 运镜是否符合要求

## 三、成本优化

| 用途 | 工具 | Token消耗 | 成本 |
|------|------|-----------|------|
| 生成图片 | Seedream | ~17,800 | ~0.18元 |
| 生成视频 | Seedance | ~246,840/5秒 | ~2.5-3.7元 |

**原则**：
- 图片用 Seedream（便宜14倍）
- 视频用 Seedance
- 先用图片确认设定，再生成视频
