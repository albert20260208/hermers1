# 欢迎来到 OpenClaw-Obsidian 知识库

这是一个集成 OpenClaw AI 助手和 Obsidian 笔记的知识管理系统。

## 目录结构

- **Inbox**: 临时笔记、收集箱
- **Areas**: 领域知识（长期关注的主题）
- **Projects**: 项目相关笔记
- **Resources**: 资源、参考材料
- **Archive**: 归档笔记
- **Templates**: 笔记模板

## 如何使用

1. **用 OpenClaw 创建笔记**: 告诉我你想要记录什么，我会帮你创建笔记
2. **用 OpenClaw 搜索笔记**: 问我相关问题，我会从知识库中查找信息
3. **用 Obsidian 编辑**: 用 Obsidian 桌面应用打开此文件夹进行可视化编辑
4. **双向同步**: 所有更改实时同步，两边都能看到

## 快速开始

- 尝试说："创建一篇关于项目计划的笔记"
- 或："搜索关于 API 集成 的笔记"
