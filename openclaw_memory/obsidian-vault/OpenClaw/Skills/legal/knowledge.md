## 二、公司法要点

### 2.1 公司类型
- **有限责任公司** - 股东2-50人，以出资额为限承担责任
- **股份有限公司** - 股东无上限，可公开发行股票
- **个人独资企业** - 1人投资，承担无限责任
- **合伙企业** - 普通合伙（无限责任）/有限合伙（有限责任）

### 2.2 股东权利
- 表决权（按出资比例）
- 分红权
- 知情权（查阅账簿）
- 优先认购权
- 剩余财产分配权

### 2.3 常见法律风险
- 抽逃出资
- 关联交易损害公司利益
- 股东会/董事会决议瑕疵
- 法定代表人越权行为

## 三、劳动法要点

### 3.1 劳动合同必备条款
1. 用人单位信息
2. 劳动者信息
3. 合同期限（固定/无固定/完成一定工作）
4. 工作内容与地点
5. 工作时间与休息休假
6. 劳动报酬
7. 社会保险
8. 劳动保护

### 3.2 试用期规定
| 合同期限 | 试用期上限 |
|---------|-----------|
| 3个月-1年 | 1个月 |
| 1年-3年 | 2个月 |
| 3年以上/无固定 | 6个月 |

- 同一用人单位与同一劳动者只能约定一次试用期
- 试用期工资 ≥ 转正工资的80%

### 3.3 经济补偿金
- N = 工作年限（满半年按1年算，不满半年按0.5年）
- 计算基数：离职前12个月平均工资
- 违法解除：2N（赔偿金）

### 3.4 竞业限制
- 适用对象：高管、高技、负有保密义务人员
- 期限：最长2年
- 补偿金：离职后按月支付（通常≥离职前工资的30%）

## 四、知识产权基础

### 4.1 著作权
- 自动产生，无需登记
- 保护期限：作者终身+死后50年
- 职务作品：一般归作者，单位有优先使用权

### 4.2 商标权
- 注册取得，有效期10年（可续展）
- 类别保护（45个类别）
- 驰名商标跨类保护

### 4.3 专利权
| 类型 | 保护期限 | 审查方式 |
|-----|---------|---------|
| 发明专利 | 20年 | 实质审查 |
| 实用新型 | 10年 | 形式审查 |
| 外观设计 | 15年 | 形式审查 |

### 4.4 商业秘密
- 不为公众所知悉
- 具有商业价值
- 权利人采取保密措施

## 五、常见法律条款解析

### 5.1 不可抗力
```
定义：不能预见、不能避免且不能克服的客观情况
常见：自然灾害、战争、政府行为
法律效果：部分或全部免责，但需及时通知
```

### 5.2 违约金与定金
- **违约金** - 约定金额，过高可请求法院调减（>损失30%）
- **定金** - 不超过合同标的20%，违约双倍返还/没收
- **注意**：违约金和定金只能择一适用

### 5.3 管辖条款
- 可约定被告住所地、合同履行地、合同签订地、原告住所地、标的物所在地
- 不得违反级别管辖和专属管辖

### 5.4 争议解决方式
- **诉讼** - 法院审判，二审终审
- **仲裁** - 一裁终局，保密性强，需有仲裁协议

## 六、AI法务助手使用指南

### 6.1 合同审查流程
1. 接收合同文本
2. 识别合同类型
3. 逐条审查关键条款
4. 标注风险点（高/中/低）
5. 提出修改建议
6. 生成审查报告

### 6.2 风险提示等级
- 🔴 **高风险** - 可能导致重大损失，必须修改
- 🟡 **中风险** - 存在不利因素，建议修改
- 🟢 **低风险** - 轻微瑕疵，可接受

### 6.3 免责声明
