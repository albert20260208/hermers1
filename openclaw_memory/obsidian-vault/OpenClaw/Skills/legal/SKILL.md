# legal/SKILL.md - 法务技能

## 描述
提供合同审查、法律条款解析、公司法、劳动法、知识产权等基础法务知识支持。

```

```

### 条款解析
```

```

## 能力范围

### ✅ 可以做的
- 合同条款风险识别
- 常见法律问题解答
- 法律概念解释
- 条款修改建议
- 法律流程说明

### ❌ 不能做的
- 出具正式法律意见书
- 代理诉讼/仲裁
- 替代执业律师
- 处理复杂专项法律事务
