## 📋 两种实现方式

### 方式A: 一人分饰多角 (当前使用)

**原理**: 我在不同阶段切换"角色视角"来审核

```
【写剧本时】
我(编剧角色): 写初稿
    ↓
我(导演角色): 审核,找问题
    ↓
我(编剧角色): 根据问题修正
    ↓
我(演员角色): 检查对白是否符合角色
    ↓
输出给海哥确认

【选镜头时】
我(摄影师A): 提出方案A + 理由
我(摄影师B): 提出方案B + 理由
    ↓
我(导演角色): 总结两个方案优劣
    ↓
海哥裁决
```

**状态**: ✅ 当前使用中

---

### 方式B: 真正的多Agent (待实现)

**原理**: 用OpenClaw的`sessions_spawn`启动多个独立Agent

```
【架构】
主Agent(贾维斯) - 导演角色,协调全局
    │
    ├─ 子Agent1 - 编剧角色
    │     └─ 专注写剧本
    │
    ├─ 子Agent2 - 摄影师角色
    │     └─ 专注镜头设计
    │
    └─ 子Agent3 - 质检角色
          └─ 专注找问题
```

**工作流程:**
```
1. 海哥给我任务: "写一个穿越唐朝的剧本"

2. 我(导演)拆解任务,派发给子Agent:
   → spawn 编剧Agent: "根据这个大纲写剧本"
   → spawn 摄影Agent: "为这个场景设计镜头"

3. 子Agent完成后返回结果给我

4. 我(导演)审核,发现问题:
   → 再派发修改任务给编剧Agent

5. 通过后,整合输出给海哥
```

**技术实现:**
```python
# 1. 派发给编剧Agent
screenwriter_result = sessions_spawn(
    task="根据以下大纲写剧本: ...",
    label="screenwriter",
    model="claude-sonnet"
)

# 2. 派发给摄影Agent
cinematographer_result = sessions_spawn(
    task="为以下场景设计镜头: ...",
    label="cinematographer"
)

# 3. 导演审核两个结果
# 4. 如有问题,再派发修改任务
# 5. 整合后输出给海哥
```

**状态**: ⏳ 待学习实现

## 📊 两种方式对比

| 维度 | 方式A (一人分饰) | 方式B (真多Agent) |
|------|-----------------|------------------|
| **实现难度** | 简单,现在就能用 | 需要配置spawn |
| **Token消耗** | 低 | 高(多个Agent) |
| **视角独立性** | 有限 | 真正独立 |
| **适合场景** | 简单项目 | 复杂大项目 |
| **质量上限** | 中 | 高 |
