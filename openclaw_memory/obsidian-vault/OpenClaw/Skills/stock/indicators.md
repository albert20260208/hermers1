# 股票金融技能

## 核心指标知识

### 周线/日线稳步上扬判断标准

> 来源：海哥分析总结
> 添加日期：2026-02-16

**核心逻辑：布林带 + 斜率 + 稳定性**

---

#### 📊 日线 vs 周线对比

| 时间 | 日线表现 | 周线表现 | 哪个更准？ |
|------|----------|----------|------------|
| 第1周 | 涨2%，跌1%，涨1%，横盘，涨1% | 周涨幅3%，收阳线 | 周线告诉你"这周在涨"，日线让你每天纠结 |
| 第2周 | 涨3%，跌2%，跌1%，涨2%，涨2% | 周涨幅4%，继续阳线 | 周线确认趋势延续，日线可能会让你想跑 |
| 第3周 | 某天突然跌4%（主力洗盘） | 周线可能只是带下影线的小阳 | 周线告诉你"洗盘而已，别慌" |

**结论**：如果你想做中长线、不想被日线波动干扰，周线是更好的判断基准。

---

#### 🎯 日线与周线配合使用

| 策略类型 | 主周期 | 辅助周期 | 用法 |
|----------|--------|----------|------|
| 长线持仓 | 周线定方向 | 日线找买点 | 周线满足"缓步上升"，日线回踩中轨时买入 |
| 波段操作 | 日线定买卖 | 周线看趋势是否完好 | 日线做波段，但周线趋势坏了就清仓 |
| 量化选股 | 先用周线筛选 | 再用日线择时 | 周线选出"慢牛股池"，日线策略从中挑时机 |

---

#### 📝 参数对比表（核心！）

| 对比项 | 日线策略 | 周线策略 | 参数设置 |
|--------|----------|----------|----------|
| 周期N | 20日 | 20周 | N = 20 |
| 斜率阈值 | 1%-5%（5天） | 5%-15%（5周） | slope_min=0.05, slope_max=0.15 |
| 稳定性判断 | 10天有7天在中上轨 | 10周有7周在中上轨 | stable_weeks >= 7 |
| 量能判断 | 5日均量 > 10日均量 | 5周均量 > 10周均量 | vol_ma5 > vol_ma10 |

---

#### 维度1：轨道本身在缓慢向上

布林带的中轨和上轨都应该有温和的上倾角度。

```python
# === 判断轨道是否缓步向上（斜率法）===
# 计算中轨过去5周的涨幅百分比
middle_slope = (middle - ref(middle, 5)) / ref(middle, 5)

# 计算上轨过去5周的涨幅百分比
upper_slope = (upper - ref(upper, 5)) / ref(upper, 5)

# 周线阈值：5%-15%（注意：比日线大！）
condition_slope = (middle_slope >= 0.05) and (middle_slope <= 0.15) and (upper_slope >= 0.05)
```

#### 维度2：股价不能忽上忽下

在缓步上升中，股价应该贴着中上轨走，而不是频繁穿越。

```python
# === 判断轨道内的稳定性 ===
# 最近10周中，至少有7周股价都在中上轨之间
days_in_zone = count(close > middle and close < upper, 10)
condition_stable = days_in_zone >= 7

# 同时，股价不能频繁触碰上轨（触碰上轨往往意味着短期过热）
days_touch_upper = count(close >= upper, 10)
condition_not_overheat = days_touch_upper <= 2  # 10周内触碰上轨不超过2次
```

#### 维度3：量能配合

```python
# === 量能判断 ===
vol_ma5 = ma(volume, 5)   # 5周均量
vol_ma10 = ma(volume, 10) # 10周均量
condition_volume = vol_ma5 > vol_ma10  # 近期量能放大
```

#### 综合判断

```python
# 稳步上扬 = 轨道缓升 + 股价稳定 + 不过热 + 量能配合
is_steady_rise = condition_slope and condition_stable and condition_not_overheat and condition_volume
```
