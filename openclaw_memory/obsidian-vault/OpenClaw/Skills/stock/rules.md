## 📜 规则一：分钟级MACD回溯检测规则

**生效日期**: 2026-02-26  
**制定背景**: 东方财富(300059) 11:00死叉漏报事件  
**规则级别**: 🔴 强制执行

### 问题描述
1. **监控非实时**：我们的监控是定时执行（如每30分钟一次），不是实时监控
2. **信号遗漏**：检测当时可能没有信号，但上一个周期内发生的信号会被遗漏
3. **时序问题**：API返回的最新K线可能是未完成的，导致判断错误

### 规则内容

**对于日线以下级别（60分钟、30分钟、15分钟、5分钟）的MACD监控：**

| K线级别 | 回溯K线数 | 覆盖时间 | 说明 |
|---------|-----------|----------|------|
| 60分钟 | 4根 | 4小时 | 覆盖上次检测到本次之间的所有K线 |
| 30分钟 | 8根 | 4小时 | 覆盖上次检测到本次之间的所有K线 |
| 15分钟 | 16根 | 4小时 | 覆盖上次检测到本次之间的所有K线 |
| 5分钟 | 48根 | 4小时 | 覆盖上次检测到本次之间的所有K线 |

**检测逻辑：**
1. 获取K线数据后，**不只检查最后一根K线**
2. **从最新K线向前回溯**，检查每一对相邻K线是否发生交叉
3. **发现交叉即返回**，记录信号发生的具体时间
4. **去重机制**：同一信号（同一股票+同一级别+同一时间点）只报告一次

**代码实现示例：**
```python
def check_cross(df, check_type='both', lookback=8):
    """
    回溯检测金叉/死叉
    lookback: 回溯K线数量
    返回: (信号类型, 发生时间) 或 (None, None)
    """
    for i in range(1, lookback + 1):
        idx = -i
        prev_idx = idx - 1
        
        prev_dif = df['dif'].iloc[prev_idx]
        prev_dea = df['dea'].iloc[prev_idx]
        curr_dif = df['dif'].iloc[idx]
        curr_dea = df['dea'].iloc[idx]
        
        cross_time = df['day'].iloc[idx]
        
        # 死叉: DIF从上向下穿越DEA
        if prev_dif >= prev_dea and curr_dif < curr_dea:
            return 'death', cross_time
        
        # 金叉: DIF从下向上穿越DEA
        if check_type == 'both' and prev_dif <= prev_dea and curr_dif > curr_dea:
            return 'golden', cross_time
    
    return None, None
```

### 去重机制

**信号唯一键**: `{股票代码}_{K线级别}_{信号类型}_{发生时间}`

**记录文件**: `data/macd_signals_sent.json`

**有效期**: 2小时（超过2小时的记录自动清除）

### 检查清单

开发新的分钟级监控功能时，必须确认：

- [ ] 是否实现了回溯检测（lookback参数）
- [ ] 回溯K线数是否覆盖检测间隔（至少4小时）
- [ ] 是否记录信号发生的具体时间
- [ ] 是否实现了去重机制
- [ ] 是否在信号输出中包含发生时间
