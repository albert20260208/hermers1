## 🚨 常见问题与解决方案

### Q1: 数据获取失败或延迟
**症状**: 脚本报错"无法获取数据"或返回空数据
**可能原因**:
1. 网络代理失效
2. 数据源API变更
3. 请求频率过高被限制

**解决方案**:
1. 检查代理设置：`curl -x socks5://proxy:port http://hq.sinajs.cn`
2. 切换数据源：修改脚本中的source参数
3. 增加请求间隔：从5秒改为10秒
4. 查看错误日志：`/root/.openclaw/workspace/logs/stock_monitor.log`

### Q2: MACD信号误报
**症状**: 频繁出现金叉/死叉信号，但股价无实际变化
**可能原因**:
1. 横盘震荡导致指标频繁交叉
2. 数据噪声或异常值
3. 参数设置过于敏感

**解决方案**:
1. 添加RSI共振过滤：只有当RSI也在超买/超卖区时才确认信号
2. 增加成交量确认：信号需伴随成交量放大
3. 调整MACD参数：尝试(8,17,9)或(10,20,7)
4. 引入三智能体辩论系统：多个指标投票决定

### Q3: 通知未送达
**症状**: 脚本运行正常但Telegram无通知
**可能原因**:
1. OpenClaw消息队列阻塞
2. Telegram API限制
3. 网络连接问题

**解决方案**:
1. 检查OpenClaw状态：`openclaw gateway status`
2. 查看消息日志：`openclaw logs --tail=20`
3. 测试消息发送：`python -c "from utils.notifier import send_alert; send_alert('test')"`
4. 添加备用通知方式（考虑邮件或钉钉）

### Q4: 内存使用过高
**症状**: 脚本运行后服务器内存持续增长
**可能原因**:
1. 数据缓存未释放
2. 循环引用导致内存泄漏
3. 历史数据积累过多

**解决方案**:
1. 定期重启脚本：通过cron每天重启一次
2. 限制历史数据：只保留最近30天数据
3. 使用内存分析工具：`python -m memory_profiler stock_monitor.py`
4. 优化数据结构：使用pandas替代纯Python列表
