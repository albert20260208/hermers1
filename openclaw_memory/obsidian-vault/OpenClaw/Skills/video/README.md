## 🎯 使用指南

### 按角色查找
- **编剧**: 进入 `编剧/` 目录
- **导演**: 进入 `导演/` 目录
- **场景设计**: 进入 `场景人物道具/` 目录
- **AI工具**: 进入 `工作流程/` 目录

### 按项目查找
- **具体项目**: 进入 `projects/` 目录下的对应项目文件夹

### 按模板查找
- **模板文件**: 进入 `templates/` 目录
