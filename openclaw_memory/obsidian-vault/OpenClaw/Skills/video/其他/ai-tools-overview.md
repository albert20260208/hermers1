# AI视频制作工具全攻略

> 更新时间: 2026-03-10
> 来源: Web Search & Research

---

## 概述

本文档整理2026年主流AI视频制作工具，涵盖剧本生成、分镜设计、视频生成三大环节。

---

## 一、剧本/脚本生成工具

### 1. Squibler
- **特点**: 几分钟内把草稿变完整剧本
- **优点**: 快速、结构完整
- **缺点**: 创意有限

### 2. FinalBit
- **特点**: 全流程工具（剧本→分镜→预算）
- **优点**: 一站式解决方案
- **缺点**: 付费较高

### 3. HeyGen
- **特点**: 剧本+70+语言本地化+虚拟人
- **优点**: 适合营销/教育内容
- **缺点**: 偏向虚拟人方向

### 4. PlayPlay
- **特点**: 输入主题→自动生成脚本
- **优点**: 免费、易用
- **缺点**: 功能较基础

### 5. Canva Magic Write
- **特点**: 脚本生成+AI生视频集成
- **优点**: 集成在Canva生态内
- **缺点**: 功能有限

---

## 二、分镜/Storyboard工具

### 1. Katalist
- **特点**: 分析脚本→自动提取角色/场景/动作
- **优点**: 自动分析能力强
- **缺点**: 偏前期筹备

### 2. Storyboarder.ai
- **特点**: 分镜制作+图生视频一体化
- **优点**: 全流程覆盖
- **缺点**: 视频质量一般

### 3. LTX Studio
- **特点**: 脚本→分镜→视频完整流程
- **优点**: 免费+Web端可用
- **缺点**: 生成时间较长

### 4. Boords
- **特点**: AI分镜+团队协作
- **优点**: 协作功能强
- **缺点**: 偏向动画方向

### 5. DomoAI
- **特点**: 分镜+角色一致性+40+语言配音
- **优点**: 功能全面
- **缺点**: 付费工具

### 6. StoryboardHero
- **特点**: 脚本结构化（含运镜/转场/配音）
- **优点**: 专业化程度高
- **缺点**: 偏商业应用

### 7. Adobe Firefly
- **特点**: Adobe生态集成
- **优点**: 与Ps/Ai无缝集成
- **缺点**: 需订阅Adobe全家桶

---

## 三、视频生成工具（文生视频/图生视频）

### 1. Runway
- **特点**: 行业标杆，功能全面
- **适用场景**: 电影、广告制作
- **状态**: 付费工具

### 2. Luma Dream Machine
- **特点**: 高质量输出+可迭代
- **适用场景**: 创意短片
- **状态**: 付费工具

### 3. Mootion
- **特点**: 2026年评测最佳综合方案
- **适用场景**: 完整剧本→成片
- **状态**: 新兴工具

### 4. Seedance (火山引擎) ✅
- **特点**: 我们正在使用的视频生成工具
- **适用场景**: 中文提示词视频
- **状态**: 已配置API
- **参考**: `skills/video/seedance-guide.md`

### 5. HeyGen
- **特点**: 虚拟人+配音
- **适用场景**: 营销、教育视频
- **状态**: 虚拟人方向强

### 6. Adobe Firefly
- **特点**: 生态完整
- **适用场景**: 专业视频制作
- **状态**: 需订阅

## 四、推荐工作流程

```
剧本创作 → 分镜设计 → 提示词优化 → 视频生成 → 后期
   ↓           ↓           ↓          ↓
 Squibler   Katalist   手动优化   Seedance/Runway
 或Canva    或LTX                 或Mootion
```

## 五、关键区别总结

| 类别 | 工具代表 | 特点 |
|------|----------|------|
| **全流程工具** | FinalBit、Mootion、LTX Studio | 从剧本到成片一键完成 |
| **专注脚本** | Squibler、PlayPlay | 剧本生成能力强 |
| **专注分镜** | Katalist、Storyboarder.ai、Boords | 分镜设计专业化 |
| **专注生成** | Runway、Luma、Seedance | 视频质量最佳 |
