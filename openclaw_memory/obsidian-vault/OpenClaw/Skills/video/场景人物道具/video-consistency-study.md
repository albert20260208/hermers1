# 视频一致性深度研究 (2026-02-28 学习笔记)

## 🎯 核心问题
多段视频拼接时，人物外观、服装、场景位置容易不一致。

---

## 一、人物一致性解决方案

### 1. 角色特征库（最强控制）
在每个片段提示词开头固定使用完整的角色描述：

```
【角色库】⭐
伊森：29岁，188cm，模特身材偏瘦，深棕色头发短刘海，黑色修身西装（单扣），
浅蓝色衬衫，黑色领带，轮廓分明的高颧骨脸，深邃眼神带哀伤
克拉拉：26岁，168cm，苗条匀称，黑长直发披肩，浅灰色无袖连衣裙，
素颜清冷表情，纤细身材，皮肤白晳，瓜子脸
```

### 2. 服装特写参考图
- 准备高清服装正面照
- 每次生成都引用该图
- 参考强度：85%

### 3. Seed值锁定
- 首次生成满意后复制Seed值
- 后续使用相同Seed
- 保持提示词完全一致

### 4. 禁止性描述
```
禁止改变以下内容：
- 伊森的西装颜色和剪裁
- 克拉拉的连衣裙
- 人物面部特征
- 发型
```

---

## 二、场景一致性解决方案

### 1. 场景锁定描述模板
```
【场景锁定】⭐
- 豪华公寓客厅，落地窗在右侧墙面
- 大理石台面在画面左侧中央
- 皮沙发在画面左侧后方
- 窗外城市灯光隐约可见
- 禁止改变家具位置
- 禁止改变光线角度（月光从右侧落地窗洒入）
```

### 2. 空间坐标定位法
用坐标描述人物位置：
- 伊森：画面右侧3/4处（X:75%, Y:50%）
- 克拉拉：画面左侧1/4处（X:25%, Y:50%）
- 两人间距：约2米

### 3. 关键帧提取法
- 用ffmpeg从上一段结尾提取帧
- 作为下一段首帧参考

## 三、今天新增的官方技巧

### 1. 分镜脚本式描述
```
镜头1：远景。夜晚豪华公寓，月光从落地窗洒入。伊森站在皮沙发旁。
镜头2：中景。伊森转身，目光转向克拉拉。
镜头3：特写。克拉拉睫毛轻颤，未抬头。
```

### 2. 禁止性描述强化
```
禁止：
- 改变人物面部
- 改变服装
- 改变站位
- 改变场景布置
- 改变光线方向
```

### 3. 精确的景别+角度+动作
```
中景（Medium Shot）：膝盖以上
近景（Close-Up）：胸部以上
特写（Extreme Close-Up）：局部放大
```

## 四、实践验证清单

每次生成后检查：
- [ ] 人物面部是否与参考图一致
- [ ] 服装颜色/款式是否一致
- [ ] 站位是否在正确位置
- [ ] 场景元素是否对齐
- [ ] 光线方向是否一致

---

## 五、进阶技巧（来自今天学习）

### 1. 摄影术语精确化
- 用"中景"而非"半身"
- 用"推近"而非"靠近"
- 用"低机位仰拍"描述角度

### 2. 连续叙事切镜
```
镜头1：房间全景
切镜至镜头2：中景伊森
切镜至镜头3：克拉拉特写
最后切回镜头1：全景
```

### 3. 风格一致前缀
所有片段添加：
```
风格：冷青白色调，月光为主光源，安静压抑，电影感
```

## 六、行业最新技术 (2026-02-28 学习)

### Vidu 1.5 多主体一致性 (重要！)
**突破性技术**: 上传1-3张参考图，实现多主体100%精确控制

**三大技术突破**:
1. **复杂主体精准控制**: 无论细节丰富的角色还是复杂物体，多角度一致性
2. **面部特征和表情自然一致**: 特写画面中面部细节和表情变化自然流畅
3. **多主体一致性**: 支持多人+物体+环境融合控制

**对比LoRA方案**:
| 方案 | 数据需求 | 时间 | 成本 |
|------|----------|------|------|
| LoRA | 20-100段视频 | 数小时 | 成百上千倍 |
| Vidu多图参考 | 1-3张图 | <30秒 | 单次生成 |

**核心洞察**: 
- 视觉模型进入"上下文时代"
- 类似语言模型的上下文学习能力
- 模型能够理解和记忆多图关联性

**贾维斯的应用启示**:
- 考虑使用Vidu作为备选方案
- 等待火山引擎类似功能上线
