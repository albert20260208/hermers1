## 🎯 服装一致性核心思路
**为什么AI会"乱换衣服"**: 每个图像是独立生成的，模型没有主动"记住"上一张图的服装细节。解决关键是：**给AI提供清晰、强制的"锚点"，让它有据可依。**

---

## 🔧 服装一致性解决方案（从易到难）

### 方法1：强化提示词中的服装结构化描述
将服装拆解为**材质、版型、部件、装饰**四层要素：

| 错误写法 | 正确写法 |
|:---|:---|
| "穿传统衣服的少女" | "穿藏青色立领盘扣短衫的少女" |
| "精致连衣裙" | "哑光真丝面料、收腰A字型、荷叶边袖口、胸前蝴蝶结" |

**进阶技巧**:
- 加入光影反应描述，如"铜扣在侧光下泛暖黄反光"
- 用【】框住关键特征并前置强调
- 禁用"华丽""复古风"等抽象词，全部替换为肉眼可判别的具象指标

### 方法2：上传服装特写参考图（精准锁定）
1. 准备一张**高清服装特写图**：人物站立，上半身正面完整，服装平整无遮挡，背景纯白
2. 在生图页面点击"导入参考图"，上传该图片
3. **关键**: 在参考图设置面板中，**手动选择"服饰特征"选项**
4. 将"参考强度"滑动至**85%**

### 方法3：双参考图分层锁定（最强控制）
- **A图**: 角色正面半身像（五官清晰、服装完整）
- **B图**: 同一套服装的**平铺特写**（无模特，仅衣物平铺于白底）
- 操作: 先导入A图设置"角色特征"65%，再导入B图设置"服饰特征"90%

### 方法4：利用Seed值固化服装
1. 首次生成满意的服装图后，复制**Seed数值**
2. 新建生成任务，**保持提示词完全不变**
3. 调整CFG Scale至**9.2**，采样步数设为**32**

### 方法5：局部重绘修复（补救措施）
1. 进入画布编辑界面，点击"涂抹重绘"
2. 用画笔**精准圈选失真服装区域**
3. 在重绘提示词框中，**仅输入该局部的服装描述**

## ⚠️ 常见问题与避坑指南

### 1. 图片与视频比例匹配
- ❌ 错误: 3:1宽图 → 视频拒绝(宽高比需在0.4-2.5之间)
- ✅ 正确: 16:9 (2848x1600) → 完美适配视频
- **教训**: 图生视频前,先确认图片比例

### 2. 模型ID要准确
- ❌ `doubao-seedream-5.0-lite` (文档里的名字)
- ✅ `doubao-seedream-5-0-260128` (实际调用ID)
- **教训**: 从控制台代码示例复制,不要猜

### 3. 多人场景的人物高度比例 ⭐重要
- **问题**: 多人同框时,身高比例不协调(主角太高或太矮)
- **解决**: 提示词中明确写入人物高度比例
- **示例**:
  ```
  主角身高约175cm,与周围行人身高比例协调一致
  人群中主角不突兀,自然融入环境
  前景人物与背景人物保持透视比例正确
  ```
- **检查点**: 生成后检查人物大小是否合理

### 4. 视频时长限制
- Seedance 1.5 Pro: 5秒或10秒
- **策略**: 复杂运镜用5秒,避免失败

### 5. 图生视频的平衡
- 提示词太多 → 可能偏离参考图
- 提示词太少 → 动态不够
- **平衡点**: 明确运镜+关键动态,其他依赖参考图

### 6. 多段视频拼接的场景与人物一致性 ⭐重要（2026-02-28）
- **问题**: 每次生成都是独立发挥，接续段容易出现场景位置、人物站位、人物外观不一致
- **原因**: AI生成具有随机性，即使提示词描述相同，每次输出可能有差异
- **解决**: 
  1. **强化场景位置锁定**: 在提示词中明确写出所有固定元素的位置关系
  2. **强化人物描述锁定**: 明确写出人物外观、服装、表情的固定特征
  3. **提取关键帧**: 用ffmpeg截取上一段结尾帧作为下一段首帧参考
  4. **禁止性描述**: 明确写出"禁止改变XXX"
  
- **提示词模板**:
  ```
  【场景与人物锁定】⭐（接续段必加）
  【环境锁定】
  - 禁止改变家具位置
  - 禁止改变光线角度
  
  【人物锁定】
  - 面部要保持原样
  - 禁止改变人物站位/服装/发型
  ```
  **注**: 各剧情根据具体场景填写对应的环境描述和人物描述

- **检查点**: 生成后检查场景元素和人物是否与上一段对齐

## ✅ 成功要点

### 1. 场景一致性控制
**方法**: 图生图/图生视频 + 参考图输入

**关键词**: 
```
保持参考图中XXX完全一致
保持参考图中的场景、建筑、色调、霓虹风格高度完全一致
```

### 2. 提示词结构化
借鉴官方示例的分块结构效果更好:
```
【场景】具体环境描述
【人物/动态】角色和动作(含身高比例)
【运镜】镜头运动方式
【风格】导演风格参考
【色彩与光线】色调+光效
【质感】渲染方式+分辨率
```

### 3. 运镜描述要具体
- ❌ 模糊: "镜头移动"
- ✅ 清晰: "镜头快速斜向上拉升爆发,如火箭般冲天,掠过建筑侧面"
- **关键**: 动作+速度+路径+效果

### 4. 导演风格融入
**王家卫风格关键词**:
- 抽帧跳跃感
- 霓虹色彩流转(红蓝绿粉紫)
- 高对比度光影
- 胶片颗粒质感
- 浅景深背景虚化

### 5. 细节丰富化
- 街道场景加入: 行人+雨伞+AR眼镜+小贩+飞行器
- 环境动态: 霓虹闪烁+数据流+云层飘动+雨后反射
- **效果**: 画面更有生命力

## 🎯 提示词技巧

### 技巧1: 三段式描述
```
1. 开场画面 (1-2秒)
2. 运镜过程 (核心动作)
3. 结尾定格 (最后1-2秒)
```

### 技巧2: 运镜+场景动态分开
```
【运镜】镜头如何移动
【场景动态】场景内元素如何变化(霓虹闪烁、人群移动)
```

### 技巧3: 镜头语言术语
| 中文 | 英文 | 效果 |
|------|------|------|
| 升降 | Crane up/down | 史诗感、揭示 |
| 推进 | Dolly in / Push in | 聚焦、强调 |
| 拉远 | Pull back / Dolly out | 揭示全景 |
| 环绕 | Orbit | 360度展示 |
| 一镜到底 | One-take | 流畅、真实感 |
| FPV视角 | FPV drone | 穿越感、沉浸 |

### 技巧4: 视觉冲击关键词
- 史诗感: epic scale, sweeping
- 震撼: stunning, breathtaking
- 流畅: smooth, fluid
- 加速: accelerating, rushing
- 电影级: cinematic, film-grade

### 技巧5: 人物比例关键词 ⭐
```
人物高度比例协调一致
主角与周围人物身高自然
透视比例正确
人物在画面中的相对大小合理
```

## 📖 Seedance 1.5 Pro 官方技巧 (2026-02-28 添加)

### 提示词公式
**主体+运动+环境（非必须）+运镜/切镜（非必须）+美学描述（非必须）+声音（非必须）**

### 核心技巧

#### 1. 描述必要的信息
- 给出主体、运动的限定描述
- 给出画面应体现的直观信息
- 善用程度副词强化效果

#### 2. 描述清晰的信息
- prompt与画面、音频形成正确对应
- 用特征指定主体，指定方式全程一致

#### 3. 精准的切镜描述
- 明确区分每个镜头，告诉模型确切的切镜信息
- 精准撰写切镜的时机
- 切镜之间有明确的景别/内容区分

#### 4. 切镜描述模板
```
镜头1 [景别]。 [场景描述]。[角色动作1]，[角色说：「台词1」]
切镜至第二镜头，第二镜头为[景别]，[角色动作2]，[角色说：「台词2」]
切镜至第三镜头，第三镜头为[景别]，[角色动作3]
最后镜头切回[景别]，[氛围描述]
```

#### 5. 声音生成技巧
**对话/画外音公式**: 性别+年龄区间+声音属性+语速+情绪基调

单人场景示例:
```
女性，年龄区间18-22岁，声音音域偏高但不尖锐，发声轻快，气声比例适中，音色明亮有弹性。语速中等偏快，语调起伏明显，情绪基线积极外向，带有轻微兴奋感。
```

对话场景示例:
```
第一位男性: 声音属性为中音域，音色自然不刻意用力，语速中等偏快，情绪基线随意带关心
第二位男性: 声音属性为中音域偏低，发声稳重，语速中等，情绪基线平和配合
```

#### 2. 摄影术语提升镜头效果

**视角(机位)**:
| 术语 | 效果 |
|------|------|
| 高机位/俯视 | 从上往下拍，如俯视森林空镜 |
| 平机位/平视 | 与主体平行，如跟拍滑板少年 |
| 低机位/仰视 | 从下往上拍，如仰拍流浪汉表情 |
| 过肩视角 | 从角色A肩后拍角色B面部 |
| 望远镜视角 | 描写远处细节，如吟游诗人 |
| 监控鱼眼视角 | 鱼眼效果，空间扭曲 |

**主体角度**:
| 术语 | 效果 |
|------|------|
| 正面 | 直面镜头，如霓虹灯前男子 |
| 侧面 | 侧面对镜头，如拉开窗帘 |
| 背面 | 背对镜头，如天台女子背影 |
| 四分之三侧 | 侧前方，立体感 |

**景别**:
| 术语 | 效果 |
|------|------|
| 远景 | 广阔地平线，主体小比例 |
| 全景 | 完整展现主体和环境 |
| 中景 | 膝盖以上 |
| 近景 | 胸部以上 |
| 特写 | 聚焦局部，如嘴唇特写 |

**运镜公式**: 起幅构图+运镜+运镜幅度+落幅构图

| 运镜 | 效果 |
|------|------|
| 推/拉 | 聚焦/揭示全景 |
| 摇 | 上下/左右转动 |
| 移 | 横向移动跟随主体 |
| 升/降 | 升降镜头 |
| 环绕 | 360度旋转 |
| 希区柯克变焦 | 推拉+变焦，眩晕效果 |
| 子弹时间 | 升格+快速环绕 |
