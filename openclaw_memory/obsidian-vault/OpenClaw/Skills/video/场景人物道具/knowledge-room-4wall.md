## 生成四面墙的提示词方法

### 核心提示词（豆包）

**生成四面墙：**
```
我要生成一个[豪华别墅]的客厅的图片，在无法直接生成风格一致的情况下，我想单独生成[客厅]的东南西北4面墙的图片，然后需要的时候再拼在一起，你帮我设计详细提示词，要求每次至生成其中一面墙，每面墙的装修风格都要保持一致，但是每面墙应该都是不同的装饰物或者视角（比如电视机、墙画、窗户、通向餐厅或者楼梯的视角画面）
```

**拼接2面墙：**
```

```

## 生成 & 拼接关键技巧（必看）

1. **比例统一**：每一面墙生成时，都固定使用16:9横版比例，确保画面尺寸、透视比例完全一致，拼接时无错位
2. **种子值固定**：如果生成平台支持设置种子值（Seed），生成第一面墙后记下种子值，后续三面墙都使用同一个种子值，能最大程度保证光影、色调、质感完全统一
3. **机位固定**：不要修改提示词里的机位、透视相关描述，避免透视错乱无法拼接
4. **地面衔接**：生成后检查画面底部的人字拼地板纹理方向一致，拼接时可完美对齐

## 方法论总结

### 核心思路
1. **分墙生成**：把一个完整场景拆成东南西北4面墙，逐一生成
2. **统一基准**：每面墙共用相同的空间基准描述（地板、色调、光影、机位）
3. **参考图滚雪球**：每生成一面墙，就把它作为下一面墙的参考图，保证风格一致
4. **两墙拼接**：用两点透视把相邻两面墙合成一个画面

### 关键要素
- **固定比例**：16:9横版
- **固定种子值**：保证光影色调统一
- **固定机位**：平视1.5米，不要改透视
- **地面衔接**：人字拼地板纹理方向一致
- **参考图递增**：墙1→墙2(参考图1)→墙3(参考图1,2)→墙4(参考图1,2,3)
