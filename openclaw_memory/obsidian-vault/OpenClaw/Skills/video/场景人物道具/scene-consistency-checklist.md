# 场景一致性检查清单

> 用于每次生成视频提示词时逐项核对，确保不遗漏

---

## 生成前必查项

### 1. 场景核心关键词 ✅
- [ ] **场景类型**（精灵王国街道/魔法森林/古堡大厅）
- [ ] **建筑风格**（欧式石建筑/木质小屋/现代建筑）
- [ ] **装饰元素**（魔法灯笼/壁炉/喷泉/石桥）

### 2. 光照与色调 ✅
- [ ] **时间**（白天/傍晚/夜晚）
- [ ] **光源**（阳光/月光/火光/魔法光）
- [ ] **色调**（暖色调/冷色调/中性）

### 3. 环境元素 ✅
- [ ] **天气**（晴朗/雾天/雨天/雪天）
- [ ] **季节**（春/夏/秋/冬）
- [ ] **氛围**（浪漫/紧张/神秘/温馨）

### 4. 参考图 ✅
- [ ] 所有分镜用同一场景参考图
- [ ] 参考图与描述匹配

### 5. 窗户布局 ✅（重要！）
- [ ] **窗户数量**：默认只有一面墙开窗，其他三面禁止开窗
- [ ] **窗户方向**：必须在描述中明确写出（如"南面落地窗"）
- [ ] **禁止描述**：四面落地窗、全景落地窗、东西南北都是窗
- [ ] **特殊要求**：只有用户明确要求"两面窗户"时才打破此规则

```
[时间] + [地点] + [建筑特点] + [装饰元素] + [氛围] + [色调]
```

### 场景1：精灵王国魔法街道
```
时间：夜晚
建筑：欧式精灵石建筑，魔法灯笼悬挂两侧
装饰：石桥流水，花坛种植发光花朵
氛围：神秘浪漫，魔法光芒
色调：月光蓝调
```

```

装饰：萤火虫漂浮，绿色迷雾
氛围：神秘未知
色调：绿色调
```

```
时间：夜晚
建筑：高大石柱，水晶吊灯

氛围：庄严豪华

```

## 检查流程

1. **确定场景** → 从模板库选一个或新建
2. **核对关键词** → 逐项检查上述必查项（1-5项）
3. **窗户布局确认** → 明确窗户方向和数量（默认一面）
4. **生成提示词** → 所有分镜保持一致
5. **生成后检查** → 对比各分镜场景是否一致
