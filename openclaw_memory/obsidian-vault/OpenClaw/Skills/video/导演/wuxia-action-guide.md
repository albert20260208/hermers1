## 🎯 调取规则 (影视制作时)

### 1. 何时调取本指南
✅ **适用场景**：
- 制作武侠、动作、古装、仙侠类视频
- 需要设计打斗、对决、轻功等动作场景
- 追求电影级运镜和音画同步效果
- 参考官方成功案例避免踩坑
- 学习最新Seedance 2.0特性应用

❌ **不适用场景**：
- 现代都市、科幻（非武侠类）、日常剧情
- 静态对话、情感戏（无动作元素）
- 纯风景、建筑展示类视频

### 2. 调取优先级
| 需求类型 | 优先调取章节 | 关键文件 |
|----------|--------------|----------|
| **新手入门** | 3.教程/工具类 | B站保姆级教程链接 |
| **灵感参考** | 1.官方武侠示例 + 2.用户创作案例 | 官方提示词、MV案例 |
| **技术实现** | 5.技术实现类 | GitHub项目、API文档 |
| **行业认知** | 4.评测分析类 | 媒体评测、行业影响 |
| **完整规划** | 全部章节 | 本指南 + knowledge.md索引 |

### 3. 调取流程
```
影视制作武侠动作类 → 调取本指南
    ↓
1. 确定项目类型 (MV/微电影/短剧)
    ↓
2. 参考对应案例章节
    ↓
3. 提取提示词模板/运镜描述
    ↓
4. 结合@参考图系统应用
    ↓
5. 检查场景一致性 (调用 scene-consistency-checklist.md)
    ↓
6. 生成视频 → 归档新经验到本指南
```
