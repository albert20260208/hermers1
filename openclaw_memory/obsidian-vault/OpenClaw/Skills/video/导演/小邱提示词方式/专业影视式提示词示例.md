## 专业影视术语详解

### 镜头技术术语
- **过肩镜头 (Over-the-shoulder shot)**: 标准对话场景镜头，增强对峙感
- **浅景深构图 (Shallow depth of field)**: 专业摄影技术，突出焦点主体
- **低调摄影 (Low-key lighting)**: 电影灯光风格，营造戏剧张力
- **大光圈长焦 (Large aperture telephoto)**: 专业镜头参数，背景虚化强烈
- **微距/长焦 (Macro/Telephoto)**: 特殊镜头应用，捕捉细节

### 灯光术语
- **柔和的漫反射光 (Soft diffused light)**: 专业灯光描述，柔和自然
- **背景光斑散乱 (Background bokeh scattered)**: 光斑效果，增强情绪

### 构图技巧
- **前景遮挡构图**: 利用前景元素增加层次感
- **画面中心偏右**: 打破对称，增加视觉张力
- **精准焦点控制**: 控制景深引导观众注意力

## 情感与技术结合分析

### 技术如何服务情感
1. **过肩镜头** → 增强对峙感和紧张关系
2. **大光圈虚化背景** → 突出人物情感，排除干扰
3. **低调摄影** → 营造沉重、戏剧性氛围
4. **浅景深构图** → 聚焦情感细节（手部动作、面部表情）

### 情感表达层次
- **女性情感**: "落寞且隐忍"、"忧伤和无可奈何的破碎感"
- **男性情感**: "儒雅且克制"、"冷静的心境"（通过手部动作暗示）
- **关系状态**: "对峙感"、"紧迫感"、"空间狭窄"

## 可优化之处

1. **音频完整设计**
   - 添加背景音乐：低沉的钢琴曲或弦乐
   - 环境音效：雨声、窗外的城市噪音
   - 完整画外音：补全对话内容

2. **视觉风格修饰符**
   - `Cinematic quality, 35mm film grain, anamorphic lens flares`
   - `Wide screen aspect ratio 2.35:1`
   - `Professional color grading with desaturated tones`

3. **转场效果明确**
   - 段落间过渡方式：匹配剪辑、焦点转移、淡入淡出
   - 节奏控制：根据情感变化调整剪辑节奏

4. **环境细节补充**
   - 场景设定：高档餐厅包间、雨夜
   - 道具描述：红酒杯品牌、桌布材质、窗外景色
   - 时间天气：夜晚、下雨、窗户上的雨滴
