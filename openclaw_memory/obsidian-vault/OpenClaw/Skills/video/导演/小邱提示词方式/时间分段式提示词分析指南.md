# 时间分段式提示词分析指南

## 示例提示词（小邱风格）

**原始提示词：**
```
0-5秒

·动态行为/剧情描述：门打开，男人的黑色皮鞋踏入画面，行李箱跟随脚步缓慢移动，箱轮与木质地板接触发出轻微摩擦声 。女人紧跟其后。

·镜头运动：固定机位低角度特写，聚焦脚部与行李箱的互动区域，保持画面稳定突出细节质感。

5-7秒

·动态行为/剧情描述：两人完全进入室内，男人停下脚步调整棕色复古行李箱位置，女人双手交叠置于身前，微微环顾四周，眼神中带着对新环境的好奇与审视。

·镜头运动：全景，固定镜头，捕捉美式复古环境与两人的互动关系，突出木质家具的纹理质感和暖黄色调氛围。

7-11秒

·动态行为/剧情描述： 男人身着笔挺黑色西装，女人穿着简约白色长裙，男人侧身单膝跪地，专注地为女人整理鞋子，女人低头温柔注视着男人。。

·镜头运动：全景固定镜头。

11-14秒

·动态行为/剧情描述：男性单膝跪地，专注姿态为女性整理鞋子；女性低头凝视，神情平静中带着一丝审视。

·镜头运动：固定机位中景镜头，男人上半身为前景虚化。
```

## 🎬 核心特点分析

### 1. 精准的时间分段结构
- **时间标注明确**：0-5s、5-7s、7-11s、11-14s，共14秒
- **段落逻辑清晰**：每个段落都有独立的时间范围和完整内容
- **时间分配合理**：关键情感场景（7-11s）分配4秒，动作场景（0-5s）分配5秒

### 2. 双重描述模式
每个段落都包含两个核心组成部分：

**A. 动态行为/剧情描述**
- 人物动作细节（黑色皮鞋踏入、调整行李箱、单膝跪地）
- 情感状态描述（好奇与审视、温柔注视、平静中带审视）
- 环境互动细节（箱轮与木质地板摩擦声）
- 服装特征（黑色西装、白色长裙）

**B. 镜头运动描述**
- 机位类型（固定机位、全景、中景）
- 拍摄角度（低角度特写）
- 焦点区域（脚部与行李箱互动区域）
- 画面效果（前景虚化、突出细节质感）

### 3. 专业的镜头语言运用
- **低角度特写**：用于开场，增强视觉冲击力
- **全景镜头**：展示环境与人物关系
- **中景镜头**：聚焦情感互动
- **前景虚化**：创造层次感和视觉焦点

### 4. 完整的叙事流程
1. **引入阶段**（0-5s）：人物进入场景，建立基本动作
2. **环境展示**（5-7s）：展示美式复古环境，人物与环境互动
3. **情感互动**（7-11s）：核心情感场景，人物关系展现
4. **情感深化**（11-14s）：情感细节特写，强化人物状态

## 🎯 符合Seedance 2.0最佳实践

### ✅ 时间分段格式
- 推荐用于10秒以上的视频
- 便于AI模型理解时间流和节奏
- 每个段落描述清晰，无歧义

### ✅ 视觉细节丰富
- 具体服装描述（黑色西装、白色长裙）
- 环境特征（美式复古、木质家具、暖黄色调）
- 动作细节（调整行李箱、单膝跪地、整理鞋子）

### ✅ 镜头指示明确
- 每个段落都有对应的镜头类型
- 指定了拍摄角度和焦点
- 画面效果描述具体

## 🔧 可优化之处

### 1. 缺少音频设计
**建议添加**：
- 背景音乐：温馨钢琴曲、轻爵士乐
- 环境音效：木质地板摩擦声、行李箱轮子滚动声、衣物摩擦声
- 情感音效：轻柔呼吸声、环境氛围音

### 2. 缺少风格修饰符
**建议添加**：
- 视觉风格：`Cinematic quality, film grain, shallow depth of field`
- 画面比例：`2.35:1 widescreen, 24fps`
- 色调氛围：`暖黄色调，美式复古氛围，柔和光影`

### 3. 未使用@引用系统
**如果使用参考素材，可以添加**：
- `@Image1 as the first frame`（参考第一帧构图）
- `@Video1's camera movement`（参考镜头运动）
- `@Audio1 as background music`（参考背景音乐）

### 4. 缺少转场效果
**段落间过渡可以更明确**：
- 淡入淡出、匹配剪辑、跳切等
- 镜头运动连贯性描述

## 💡 使用建议

### 1. 适用场景
- 情感叙事短片（14-30秒）
- 产品展示视频（需要情感共鸣的产品）
- 品牌故事短片
- 电影预告片风格内容

### 2. 时间分配原则
- 引入阶段：20-30%总时长
- 发展阶段：30-40%总时长  
- 高潮阶段：20-30%总时长
- 结束阶段：10-20%总时长

### 3. 情感节奏控制
- 开场：悬念或引入
- 发展：情感建立
- 高潮：情感释放
- 结尾：情感余韵

### 4. 与Seedance 2.0结合的最佳实践
1. **明确时间分段**：每个段落不超过5秒
2. **双重描述结构**：行为+镜头的组合
3. **具体视觉细节**：颜色、材质、动作细节
4. **完整音频设计**：音乐+音效+氛围
5. **风格修饰符**：添加专业视觉风格描述
