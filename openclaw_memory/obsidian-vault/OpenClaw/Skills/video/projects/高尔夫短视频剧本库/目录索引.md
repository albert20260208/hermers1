## 🎬 详细索引

### 【G001】《第19洞》- 治愈励志系列

**基本信息**
- **主题**：人生不是18洞完美，而是每一杆都尽力
- **风格**：治愈系、轻励志、电影感
- **适用平台**：视频号、抖音（情感向）、小红书
- **人物关系**：前下属拯救前领导，职场权力反转

**核心设定**
- 林骁：39岁男性，互联网总监，经历裁员危机，中年焦虑
- 苏晴：28岁女性，自由设计师，洒脱通透，技术好
- 关系：前上下级 → 精神救赎者

**剧本结构**
- 第一幕：崩溃（职场失败+球场受挫）
- 第二幕：对话（苏晴开导，高尔夫哲学）
- 第三幕：回忆蒙太奇（职场失败闪回）
- 第四幕：重生（挥杆重生，走向下一洞）

**金句**
- "39岁而已，人生还有19洞呢"
- "这里不在乎你40岁前有多成功，只在乎你下一杆怎么打"
- "不是birdie，但...可以继续"

**系列延展**
- 第2集：林骁带苏晴谈生意，高尔夫哲学拿下客户
- 第3集：林骁老婆出场，关于"完美婚姻"的对话
- 第4集：林骁重回职场，心态转变帮助年轻人

### 【G002】《球杆女王》第1集 - 爽剧系列

**基本信息**
- **副标题**：被嘲笑的练习场
- **主题**：你以为我只是来摆拍的？姐是来教你做人的
- **风格**：爽剧/逆袭/女性成长/打脸
- **适用平台**：抖音、快手（强节奏）、小红书
- Slogan：隐退三年，回来发现全世界都忘了我曾是世界冠军

**核心设定**
- 沈念：28岁女主，隐退职业球员，前国家队队长，亚锦赛冠军，世界排名第三
- 苏媚：反派女，网红主播，golf媛人设
- 周扬：渣男，沈念前男友，跟苏媚暧昧
- 王教练：势利眼小丑角色

**剧本结构**
- 第一幕：羞辱（被看不起、前男友现女友嘲讽）
- 第二幕：打脸（S杆215码、一杆进洞、连续五球全中）
- 第三幕：身份揭露（董事长亲自邀请、继承皇家俱乐部51%股份）
- 第四幕：钩子（下周三股东大会对决）

**爽点设计**
1. 被说高尔夫媛 → S杆215码打脸
2. 连续五球全中，围观群众惊呼
3. 董事长亲自邀请，年薪500万
4. "别什么垃圾都捡，脏"（嘴炮暴击）
5. 遗嘱线索：继承亚洲最大连锁球场
6. "我不稀罕500万，因为我即将拥有整个帝国"

**系列延展**
- 第2集：董事会打脸，让渣男跪着打球
- 第3集：球场收购战，职场博弈
- 第4集：国际比赛，神秘男主出场
