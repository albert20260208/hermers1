# 偏爱难藏海外改编项目
## Hidden Preference Overseas Adaptation Project

### 项目概述
本项目旨在将中国短剧《偏爱难藏》（原著小说《婚既钟情》）改编为面向北美市场的影视作品。项目类型为90分钟浪漫喜剧电影或8集限定剧。

**原剧信息**：
- 中文名：《偏爱难藏》
- 原著小说：《婚既钟情》（番茄小说平台）
- 主演：鹿单东（饰周望津）、澄芓（饰林序秋）
- 题材：现代都市/甜宠/先婚后爱

**改编目标**：
- 保留原著核心情感线（契约婚姻→真实爱情）
- 进行文化适配（中国家族联姻→西方商业联姻）
- 符合北美观众审美和价值观
- 打造具有国际竞争力的浪漫喜剧IP

### 核心原则
1. **保留情感核心**：契约婚姻到真实爱情的转变过程
2. **文化适配**：中国家族观念→西方个人主义+商业利益
3. **现代背景**：融入科技、职场、社交媒体元素
4. **国际视野**：场景全球化，角色多元化
