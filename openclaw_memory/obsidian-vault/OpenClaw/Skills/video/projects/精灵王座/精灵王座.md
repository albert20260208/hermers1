## 📖 故事背景（基于原电影）

### 剧情概述
《精灵王座》是改编自3D动作网游《龙之谷》的国产动画电影，讲述人类少年小鱼与精灵恋人莉雅为营救被黑暗精灵劫持的精灵女王，共同踏上冒险征程的故事。

**核心主题**：爱与梦想、跨越种族与生死的命题、异世界同生死的爱情

### 主要角色

| 角色 | 身份 | 关系 |
|------|------|------|
| **小鱼** | 人类少年，屠龙英雄，的铁匠 | 莉雅的男朋友 |
| **莉雅** | 精灵族弓箭手 | 小鱼的恋人 |
| **精灵女王玫尔** | 精灵王国统治者 | 莉雅的姐姐 |
| **黑暗精灵玫拉** | 反派 | 企图夺取生命宝玉 |
| **精灵王凯尔** | 精灵战士 | 莉雅的哥哥 |

### 故事线（改编自原电影）

1. **战后和平**：黑龙被击败后，小鱼回到人类王城拜铁匠为师，开始平凡生活；精灵王国在精灵女王统治下欣欣向荣
2. **婚礼重逢**：几年后，在精灵女王婚礼上，小鱼和莉雅终于重逢
3. **恋情受阻**：精灵世界一致反对小鱼和莉雅的恋情（古训：人类与精灵结合将带来灾难）
4. **黑暗来袭**：黑暗精灵闯入婚礼，企图夺走维系精灵世界稳定的生命宝玉
5. **冒险开始**：小鱼和莉雅踏上拯救女王、对抗黑暗的冒险旅程

### 世界观设定

- **精灵王国**：位于精灵王座，由精灵女王统治，与人类世界有隔阂
- **宝玉设定**：
  - **生命宝玉**：维系精灵世界稳定的神器
  - **黑暗宝玉**：黑暗精灵的力量来源
- **古训约束**：人类与精灵结合会带来灾难

## 📝 审核经验记录（2026-03-20）

### ❌ 审核不过的教训

**原因分析**：
1. **脸部描写过多**：详细的面部特征描述（混血面容、深邃碧绿眼眸、柳眉倒竖、樱桃小嘴等）触发真人人脸审核
2. **灵异/迷信词汇**：巫师、灵魂、魔法、复活等词汇
3. **黑暗元素**：黑暗宝玉、黑色邪气、杀 气等负面词汇

### ✅ 解决方案

| 问题 | 解决方案 |
|------|----------|
| 巫师/灵魂 | 改为"神秘黑袍法师"/"光影化身" |
| 黑暗宝玉 | 改为"神秘宝玉"/"蓝色宝玉" |
| 黑色邪气 | 改为"暗色能量" |
| "你已经死了" | 改为"你已经消失了" |
| 脸部过多（审核不过时） | 改为被光晕包裹/兜帽遮挡 |

### 📌 后续原则

1. ✅ 脸部描写保留，效果更好
2. ⚠️ 只有审核不过时再隐藏
3. ✅ 灵异/黑暗词汇先改掉（较敏感）
4. ✅ 有脸部写清楚，无脸部写清楚隐藏方式
