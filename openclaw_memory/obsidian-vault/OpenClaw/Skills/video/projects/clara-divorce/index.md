## 🎬 可复用模板

### 模板1：豪门情感开场
```
[时间]的[月光/灯光]从[落地窗/窗户]洒进来。
[地点]安静得近乎压抑。
[人物1]站在[位置]，身姿[形容词]。
[人物2]站在几步之外，[动作]，神情[情绪]。
[道具]放在[位置]上。
镜头[运镜方式]。
```

### 模板2：克制对话场景
```
[人物1][动作]，目光落在[人物2]身上。
（[人物1]轻声，带着[情绪]）"[英文对话内容]"
[人物2][微表情反应]。
（[人物1]继续）"[英文对话内容]"
镜头切换：[镜头类型]。
```

### 模板3：礼物拒绝桥段
```
[人物1]从[位置]取出[礼物描述]。
（[人物1]）"[礼物赠送台词]"
[人物2]缓缓[动作]，没有接。
（[人物2]客气而坚定）"[拒绝台词]"
[人物1][肢体反应]。
```

## 📚 组合使用指南
