## 🚫 过审专用流程（提示词审核时只调用此部分）

```
过审流程：扫描提示词 → 查找敏感词 → 列出建议 → 用户确认

专用文件：
1. 工作流程/sensitive-words.md （敏感词库与替代词）
2. 工作流程/prompt-generation-mustread.md#审核避坑 （审核避坑指南，包含脸部描写限制等）
禁用文件：所有镜头设置知识文件（见下方"镜头设置知识库"）

⚠️ 重要：过审流程只做敏感词检测，不调用任何镜头/导演/场景/编剧知识
```

## 🎯 提示词制作全流程（重要！）

**触发条件**：用户提出"提示词制作"、"写提示词"、"生成提示词"、"做视频提示词"等相关需求

**调用原则**：提示词制作是交叉性任务，涉及编剧、导演、场景、工具多个环节，必须调用全部相关文件，不可细分省略。

### 必调文件清单（按顺序）

| 顺序 | 文件路径 | 用途 | 说明 |
|------|----------|------|------|
| 1 | `编剧/screenwriting.md` | 故事结构 | 确定叙事框架、情感曲线 |

| 3 | `导演/director-styles.md` | 风格选择 | 确定导演风格参考 |

| 6 | `导演/wuxia-action-guide.md` | 动作设计 | 如涉及武侠/动作场景 |
| 7 | `导演/seedance-prompt-en.md` | 英文提示词 | 如需要英文版本 |
| 8 | `场景人物道具/scene-consistency-checklist.md` | 一致性检查 | 确保场景连贯 |

## 2️⃣ 知识管理规则

### 存档规则
```
检查重复 → 检查冲突 → 提醒用户 → 用户选择 → 执行存档
```

### 规则调整规则
```
检查触发词是否已有 → 检查调取文件是否匹配 → 提醒用户 → 用户选择 → 更新规则
```

### 目录调整规则
当文件在不同分类间移动时：
1. 更新此调用规则表中的文件路径
2. 检查触发关键词是否需要调整
3. 测试调用路径是否正确
4. 备份旧版本规则文件
