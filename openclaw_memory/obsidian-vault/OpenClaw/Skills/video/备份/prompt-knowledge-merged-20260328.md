## 二、导演部分

### 2.1 6位大师导演风格

#### 希区柯克 (Alfred Hitchcock)
**标志性技巧**: 悬念构建、主观镜头

**核心技法:**
- **悬念 vs 惊吓**: 让观众知道桌下有炸弹（5分钟紧张）> 炸弹突然爆炸（5秒效果）
- **主观镜头 (POV)**: 让观众通过角色的眼睛看世界
- **希区柯克变焦 (Dolly Zoom)**: 镜头推进+焦距拉远，产生眩晕效果
- **麦格芬 (MacGuffin)**: 推动剧情但本身不重要的物品

**提示词应用:**
```
希区柯克风格:
- 主观POV镜头
- 缓慢推进制造压迫感
- 阴影和光线对比强烈
- 角色表情特写传递恐惧
```

#### 库布里克 (Stanley Kubrick)
**标志性技巧**: 对称构图、一点透视

**核心技法:**
- **对称构图**: 画面左右完全对称，营造庄严/不安感
- **一点透视**: 所有线条汇聚到中心，引导视线
- **广角镜头**: 强调空间感，人物渺小

**提示词应用:**
```
库布里克风格:
- 完美对称构图
- 一点透视汇聚中心
- 广角镜头强调环境
- 冷色调，几何线条
```

#### 王家卫 (Wong Kar-wai)
**标志性技巧**: 抽帧、霓虹色彩、时间流逝感

**核心技法:**
- **抽帧 (Step-printing)**: 动作不连贯，梦幻感
- **霓虹色彩**: 高饱和冷暖对比
- **慢动作**: 强调瞬间情绪
- **画外音**: 内心独白

**提示词应用:**
```
王家卫风格:
- 抽帧跳跃感，动作不连贯
- 霓虹灯色彩，冷暖对比强烈
- 慢动作特写
- 都市夜景，玻璃反光
```

#### 诺兰 (Christopher Nolan)
**标志性技巧**: 非线性叙事、IMAX实拍、时间概念

**核心技法:**
- **时间折叠**: 多条时间线并行
- **实拍特效**: 真实爆炸、翻转卡车
- **IMAX画幅**: 1.43:1或1.78:1
- **低音配乐**: 紧张感音效

**提示词应用:**
```
诺兰风格:
- 宏大场面，IMAX画幅
- 实拍特效，真实爆炸
- 时间折叠视觉化
- 低音震动，紧张配乐
```

#### 斯皮尔伯格 (Steven Spielberg)
**标志性技巧**: 情感共鸣、奇观场面

**核心技法:**
- **面部特写**: 捕捉细微情感
- **逆光轮廓**: 神圣感、希望感
- **奇观 reveal**: 缓慢展示震撼场面

**提示词应用:**
```
斯皮尔伯格风格:
- 逆光轮廓光，神圣感
- 面部特写捕捉情感
- 奇观场面缓慢 reveal
- 温暖色调，情感共鸣
```

#### 昆汀·塔伦蒂诺 (Quentin Tarantino)
**标志性技巧**: 非线性叙事、暴力美学、对话驱动

**核心技法:**
- **章节式结构**: 分段叙事
- **暴力美学**: 血腥但艺术化
- **流行文化引用**: 音乐、电影梗

**提示词应用:**
```
昆汀风格:
- 章节标题卡
- 暴力美学，血腥艺术化
- 70年代复古滤镜
- 流行音乐配乐
```

### 2.2 镜头语言完全指南

#### 基础运动
| 中文 | 英文 | 效果 |
|------|------|------|
| 推进 | Push in / Dolly in | 镜头向前，聚焦强调 |
| 拉远 | Pull back / Dolly out | 镜头向后，展示环境 |
| 平移 | Pan | 水平转动，扫描场景 |
| 摇镜 | Tilt | 垂直转动，展示高度 |
| 跟拍 | Track/Follow | 跟随主体移动 |
| 环绕 | Orbit / Arc | 绕主体旋转 |
| 一镜到底 | One-take | 无剪辑连续 |

#### 高级技巧
| 中文 | 英文 | 效果 |
|------|------|------|
| 希区柯克变焦 | Hitchcock zoom | 眩晕、不安 |
| 鱼眼镜头 | Fisheye | 超广角变形 |
| 低角度 | Low angle | 仰拍，权力感 |
| 高角度 | High angle | 俯拍，脆弱感 |
| 鸟瞰 | Bird's eye | 正上方俯视 |

| 中文 | 英文 | 范围 |
|------|------|------|

### 2.3 武侠动作指导

#### 动作设计原则
1. **起承转合**: 每个动作有开始、发展、高潮、结束
2. **虚实结合**: 真实武术+夸张特效
3. **兵器特性**: 剑的灵动、刀的刚猛、枪的远程

#### 经典招式提示词
```
剑法:
- 剑花挽动，寒光闪烁
- 点、刺、挑、削，行云流水
- 剑气纵横，飞叶伤人

刀法:
- 大开大合，刀风呼啸
- 劈、砍、撩、剁，势大力沉
- 刀光如雪，一刀两断

轻功:
- 足尖点地，飞身而起
- 踏雪无痕，凌波微步
- 飞檐走壁，身轻如燕
```

### 2.5 时间分段式提示词分析（小邱风格）

#### 示例提示词
```
0-5秒
·动态行为/剧情描述：门打开，男人的黑色皮鞋踏入画面，行李箱跟随脚步缓慢移动...
·镜头运动：固定机位低角度特写...

5-7秒
·动态行为/剧情描述：两人完全进入室内，男人停下脚步调整棕色复古行李箱位置...
·镜头运动：全景，固定镜头...

7-11秒
·动态行为/剧情描述：男人身着笔挺黑色西装，女人穿着简约白色长裙...
·镜头运动：全景固定镜头...

11-14秒
·动态行为/剧情描述：男性单膝跪地，专注姿态为女性整理鞋子...
·镜头运动：固定机位中景镜头...
```

#### 核心特点
1. **精准的时间分段** - 0-5s、5-7s、7-11s、11-14s，每个段落都有明确时间范围和内容
2. **双重描述结构** - 每个段落包含：动态行为/剧情描述 + 镜头运动描述
3. **专业的镜头语言** - 低角度特写、全景、中景、前景虚化等专业术语
4. **完整的叙事流程** - 引入→环境展示→情感互动→情感深化

#### 符合Seedance 2.0最佳实践
- ✅ **时间分段格式** - 推荐用于10秒以上的视频
- ✅ **视觉细节丰富** - 具体服装、环境、动作细节
- ✅ **镜头指示明确** - 每个段落都有对应的镜头类型和运动

#### 可优化之处
1. **添加音频设计** - 背景音乐、环境音效、情感音效
2. **添加风格修饰符** - `Cinematic quality, film grain, shallow depth of field`
3. **使用@引用系统** - 如果有参考素材，可用`@Image1 as the first frame`
4. **明确转场效果** - 段落间的过渡方式

#### 完整优化示例
```
0–5秒：门打开，男人的黑色皮鞋踏入画面...镜头运动：固定机位低角度特写...
音频设计：背景音乐-温馨钢琴曲，音效-木质地板摩擦声
视觉风格：电影质感，浅景深，暖黄色调，美式复古氛围
```

#### 使用建议
- **适用场景**：情感叙事短片（14-30秒）、品牌故事短片
- **时间分配原则**：引入20-30%、发展30-40%、高潮20-30%、结束10-20%
- **情感节奏控制**：开场悬念→发展建立→高潮释放→结尾余韵

### 2.6 专业影视式提示词分析

#### 示例提示词
```
正对窗户左侧为男主位置，正对窗户右侧为女主位置

0-5秒
画面构图：过肩镜头（Over-the-shoulder shot）。利用前景中模糊的男主轮廓作为遮挡，视角聚焦在女主的特写上，强调对峙感。
人物站位：女主位于画面中心偏右，与前景中的阴影男主相对而坐，空间狭窄且充满紧迫感。
人物姿态：女主身体略微前倾，双手交叠置于膝部。神情落寞且隐忍，双眼略显红肿，带有淡淡的忧伤和无可奈何的破碎感。
氛围/灯光：柔和的漫反射光。光线柔和地打在女性面部，突出其细腻的皮肤纹理，色彩饱和度适中，基调略显沉重。
镜头/焦距：特写镜头，大光圈长焦。背景完全虚化为光斑，极大地增强了人物的情绪张力。
镜头运动：固定镜头
男主画外音：Ella,Today, our marriage...

5-8秒
画面构图：低角度细节特写。采用浅景深构图，焦点精准汇聚在男主的手部和红酒杯底座。
人物站位：镜头极低，聚焦于桌面水平线上。
人物姿态：一只指节分明的手正轻稳地端起红酒杯轻微摇晃，指尖用力均匀，动作儒雅且克制，透露出人物冷静的心境。
氛围/灯光：低调摄影（Low-key）。光线集中在手部和红酒杯底座，背景光斑散乱，充满戏剧张力。
镜头/焦距：微距/长焦。极浅的景深使得背景完全抽象化，强调动作的瞬间性。
```

#### 核心特点
1. **高度结构化描述框架** - 7个固定要素：画面构图、人物站位、人物姿态、氛围/灯光、镜头/焦距、镜头运动、画外音
2. **专业影视术语运用** - 过肩镜头、浅景深构图、低调摄影、大光圈长焦、微距/长焦等专业术语
3. **情感与技术的深度结合** - 技术参数直接服务情感表达（如大光圈虚化背景→增强情绪张力）
4. **多维度完整描述** - 视觉、听觉、时间、空间、情感五个维度全面覆盖

#### 技术参数专业度
- **光学参数**：特写镜头，大光圈长焦，背景虚化为光斑（Bokeh效果）
- **灯光设计**：柔和的漫反射光，低调摄影（Low-key lighting），光线精准控制
- **构图技巧**：前景遮挡构图，画面中心偏右打破对称，浅景深聚焦

#### 与小邱风格对比
| 特征 | 小邱风格 | 影视专业风格 |
|------|----------|--------------|
| **结构** | 双重描述（行为+镜头） | 7要素结构化描述 |
| **专业度** | 中等（基础镜头语言） | 高级（电影专业术语） |
| **技术参数** | 基础（机位、角度） | 详细（光圈、焦距、灯光类型） |
| **适用场景** | 情感叙事短片 | 专业影视制作、电影风格 |

#### 可优化之处
1. **音频完整设计** - 添加背景音乐、环境音效、完整画外音
2. **视觉风格修饰符** - `Cinematic quality, 35mm film grain, anamorphic lens flares`
3. **转场效果明确** - 段落间过渡方式（匹配剪辑、焦点转移等）
4. **环境细节补充** - 场景设定、道具描述、时间天气

#### 使用建议
- **适用场景**：专业影视制作、高质量品牌内容、电影风格短片
- **目标受众**：专业影视制作者、高端品牌客户、艺术院校学生
- **模型适配**：Seedance 2.0、Runway Gen-3、Pika Labs（支持详细技术参数）
- **创作流程**：先情感目标→再技术手段→多维度检查→测试迭代

### 3.1 场景一致性检查清单

#### 场景描述公式
```
[时间] + [地点] + [建筑特点] + [装饰元素] + [氛围] + [色调]
```

#### 检查要点
1. **场景关键词固定** - 类型+建筑+装饰
2. **光照与色调统一** - 时间+光源+色调
3. **环境元素一致** - 天气+季节+氛围
4. **参考图复用** - 所有分镜用同一张

### 3.2 四面墙场景一致性方法

**核心概念:**
- 想象场景是一个房间的四堵墙
- 确定每面墙的位置和特征
- 所有镜头必须遵守这个空间布局

**应用步骤:**
1. 绘制场景平面图
2. 标注四面墙的特征
3. 确定角色在场景中的位置
4. 所有镜头必须符合空间逻辑

### 3.3 制作贴士

#### 人物一致性要素
- 发色、发型、发饰
- 面部特征
- 身材描述
- **身高比例**（与周围人物协调）

#### 服装一致性要素
- 服装类型和颜色
- 服装细节
- 配饰

#### 场景一致性要素
- 建筑特征
- 环境元素
- 氛围色调
