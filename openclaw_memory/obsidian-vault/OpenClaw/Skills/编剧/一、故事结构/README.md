# 故事结构体系

> 四大结构体系对比与适用场景

---

## 四大结构一览

| 结构 | 适用 | 集数 | 核心特点 |
|------|------|------|----------|
| **四段式（起承转合）** | 竖屏短剧 | 80集 | 情绪递进，强反转 |
| **三幕结构** | 通用 | 电影/长剧 | 25%/50%/25% |
| **Save the Cat 15节拍** | 商业电影 | 90-120分钟 | 节拍器式节奏 |
| **英雄之旅** | 冒险/成长 | 通用 | 12阶段精神成长 |

---

## 如何选择

- **竖屏短剧80集** → 用四段式，天然适配集束式追剧节奏
- **院线电影/美剧** → 用三幕结构，好莱坞标准格式
- **商业类型片** → 用Save the Cat，节拍清晰便于对标
- **个人成长/奇幻冒险** → 用英雄之旅，神话原型力量
