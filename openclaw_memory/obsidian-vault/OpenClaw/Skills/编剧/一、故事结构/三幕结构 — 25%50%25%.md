# 三幕结构 — 25%/50%/25%

> 经典好莱坞剧本结构，适合90-120分钟影视内容

---

## 基础框架

```
第一幕 (25%)  → 建置 Setup
第二幕 (50%)  → 对抗 Confrontation
第三幕 (25%)  → 解决 Resolution
```

---

## 第一幕：建置 (25%)

**时长**：约22-30分钟（90分钟电影）

**核心任务**：
1. 展示主角的"日常世界"
2. 建立主角的性格和处境
3. 引入主要人物（反派/盟友/爱情对象）
4. 抛出核心主题
5. 激励事件打破平衡
6. 进入"新世界"（第一转折点）

### 标准场景序列

| 场景 | 内容 |
|------|------|
| 开场画面 | 展示主角当前状态（最好与结局形成对比）|
| 主题揭示 | 有人说出故事核心主题（主角可能不认同）|
| 日常世界 | 主角生活/工作/性格展示 |
| 人物关系 | 关键人物一一登场 |
| 激励事件 | 打破平衡的事件（不能撤销）|
| 第一转折点 | 主角决定接受挑战 |

### 激励事件示例

- 《美女与野兽》：贝儿父亲被抓
- 《泰坦尼克号》：杰克赢得船票
- 《哈利波特》：霍格沃茨来信

---

## 第二幕：对抗 (50%)

**时长**：约45-60分钟（90分钟电影）

**核心任务**：
1. 主角在新世界中尝试解决问题
2. 遇到盟友和敌人
3. 不断升级的障碍和冲突
4. 中点转折（假胜利或假失败）
5. 主角跌入最低谷
6. 准备进入最终决战

### 第二幕结构

```
上升动作 (第1-2幕之间)  → 主角尝试，屡有进展
中点 (50%)              → 重大转折，关系/局势大变
下降动作 (第2-3幕之间)  → 困难加剧，最低谷临近
第二转折点              → 进入最终决战
```

### 中点标记

中点必须是一次重大转变：

- **假胜利**：看似成功了，但代价惨重
  - 例：抓住反派，但发现更大阴谋
- **假失败**：看似全完了，但有转机
  - 例：失去一切，但获得关键盟友

### 最低谷

主角经历"灵魂黑夜"：
- 失去最重要的东西
- 所有希望破灭
- 质疑自己为什么要做这件事

---

## 第三幕：解决 (25%)

**时长**：约22-30分钟（90分钟电影）

**核心任务**：
1. 最终对决（物理或心理）
2. 解决核心矛盾
3. 主角完成成长弧线
4. 回应开场画面
5. 自然收尾

### 结局模板

```
高潮 → 主角用第二幕学到的东西解决问题
结局 → 新的平衡建立
终场画面 → 与开场形成对照，暗示改变
```

---

## 故事转折点清单

| 节拍 | 位置 | 内容 |
|------|------|------|
| 激励事件 | 12% | 打破平衡，不能撤销 |
| 第一转折点 | 25% | 进入新世界 |
| 中点 | 50% | 重大转折（假胜/假败）|
| 第二转折点 | 75% | 进入最终决战 |
| 高潮 | 88-90% | 终极对决 |
| 结局 | 90-100% | 收拾线索 |

---

## 短剧适配

对于竖屏短剧，将三幕结构映射到80集：

```
第一幕 (1-20集)  → 建立日常 + 激励事件
第二幕 (21-60集) → 上升+中点+下降
第三幕 (61-80集) → 最终对决 + 收尾
```

---

_适用于：院线电影、长剧集、美剧_
