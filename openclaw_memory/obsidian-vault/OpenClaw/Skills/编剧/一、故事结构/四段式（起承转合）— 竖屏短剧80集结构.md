# 四段式（起承转合）— 竖屏短剧80集结构

> 专为竖屏短剧设计的情绪递进结构，适合80集篇幅

---

## 核心框架

```
起 (1-20集)   → 建置日常，埋下伏笔
承 (21-40集)  → 感情升温，甜蜜互动
转 (41-60集)  → 矛盾爆发，反转密集
合 (61-80集)  → 高潮对决，大团圆/悲剧结尾
```

---

## 详细分集指南

### 第一阶段：起 (1-20集)

**目标**：建立主角人设、展现日常世界、抛出核心悬念

| 集数 | 内容 | 情绪基调 |
|------|------|----------|
| 1-3 | 主角登场，展示独特性格/处境 | 轻松/好奇 |
| 4-7 | 遇见重要人物（男主/女主）| 心跳加速 |
| 8-12 | 建立关系基础，甜蜜铺垫 | 甜 |
| 13-16 | 暗藏矛盾或危机伏笔 | 微紧张 |
| 17-20 | 第一个大转折，引出核心冲突 | 震惊 |

**本集结尾钩子**：「她发现丈夫竟然还活着……」（第20集）

---

### 第二阶段：承 (21-40集)

**目标**：感情线深入，主角关系升级，反派势力显现

| 集数 | 内容 | 情绪基调 |
|------|------|----------|
| 21-24 | 主角面对新情况，适应变化 | 紧张 |
| 25-28 | 感情升温，关键约会/事件 | 甜 |
| 29-32 | 外部压力出现（家族/敌人）| 担忧 |
| 33-36 | 关系出现第一次危机 | 虐 |
| 37-40 | 重大真相揭露 | 震惊/虐 |

**本集结尾钩子**：「他不是他……他是谁？」（第40集）

---

### 第三阶段：转 (41-60集)

**目标**：核心矛盾爆发，连续反转，情绪最激烈

| 集数 | 内容 | 情绪基调 |
|------|------|----------|
| 41-44 | 主角陷入最低谷 | 虐 |
| 45-48 | 反击契机出现 | 希望 |
| 49-52 | 身份反转/真相大白的铺垫 | 紧张 |
| 53-56 | 重大反转 | 震惊 |
| 57-60 | 主角做出关键抉择 | 紧张/虐 |

**本集结尾钩子**：「原来一切都是他布的局……」（第60集）

---

### 第四阶段：合 (61-80集)

**目标**：最终对决，收拾所有线索，情感收尾

| 集数 | 内容 | 情绪基调 |
|------|------|----------|
| 61-64 | 最终对决准备 | 紧张 |
| 65-68 | 高潮对决/生死抉择 | 极紧张 |
| 69-72 | 收尾主要矛盾 | 释然 |
| 73-76 | 情感归宿，交代配角结局 | 温馨 |
| 77-80 | 大结局，主角完成成长弧线 | 满足/感动 |

## 竖屏短剧特殊技巧

### 1. 每3集一个小反转

```
第3集 → 发现一个新线索
第6集 → 关系更进一步
第9集 → 突然出一个危机
第12集 → 反派登场或升级
```

### 2. 每20集一个大转折

```
第20集  → 核心设定揭露（她失忆了）
第40集  → 身份反转（他是敌人的卧底）
第60集  → 最低谷（孩子没了/公司破产）
第80集  → 终极对决与团圆
```

### 3. 反派每20集升级一次

```
1-20集  → 小阻碍（误会）
21-40集 → 正面敌人（情敌/对手）
41-60集 → 终极BOSS（家族阴谋/身份秘密）
61-80集  → 最后对决+洗白机会
```

### 4. 情绪公式

```
甜 → 虐 → 甜 → 更深的虐 → 反转甜 → 超级大虐 → HE/TE
```

## 实操模板

### 开场公式（第1-3集）

```
第1集：主角日常 + 独特能力/处境 + 遇见重要人物
第2集：关系建立 + 小打小闹互动 + 埋下命运羁绊
第3集：第一集束结尾钩子，吸引继续看
```

### 第20集模板

```
激励事件：主角的日常生活被彻底打破
常见桥段：发现丈夫还活着 / 发现自己不是亲生 / 意外怀孕
```

---

_适用于竖屏短剧、抖音短剧、快手短剧_
_集数可根据目标平台调整（60集/80集/100集）_
