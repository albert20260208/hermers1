# 台词技巧体系

> 从对白基础到高级技巧的完整方法论

---

## 核心原则

**每句台词必须至少满足一个功能，否则删掉。**

---

## 五大模块

| 模块 | 核心内容 |
|------|----------|
| **三大功能** | 信息传递 / 性格塑造 / 行动驱动 |
| **潜台词** | 说A想B，表面与内在的反差 |
| **角色声音区分** | 用词/句长/节奏/态度四维度 |
| **塔伦蒂诺秘诀** | 闲聊/转折/台词即景点 |
| **冲突对白模板** | 六步升级结构 |

---

## 常见问题自检

- [ ] 台词太直白 → 加潜台词
- [ ] 所有人说话一样 → 用四维度区分
- [ ] 台词太长 → 拆成短句
- [ ] 废话太多 → 删掉"嗯""啊"
- [ ] 没有推动剧情 → 确认每句有功能
