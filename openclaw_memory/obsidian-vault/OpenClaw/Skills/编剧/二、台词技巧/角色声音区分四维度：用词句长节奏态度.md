# 角色声音区分四维度：用词/句长/节奏/态度

> 让每个角色说话都不一样——遮住名字也能认出谁在说

---

## 为什么要区分

**检验方法**：遮住角色名，只看台词，能不能猜出是谁说的？

如果猜不出 → 角色声音不够独特。

---

## 四维度详解

### 维度1：用词 (Diction)

**决定因素**：
- 文化程度
- 职业背景
- 地域特征
- 口头禅

**示例对比**：

| 角色 | 用词风格 |
|------|----------|
| 教授 | "从理论上而言，这种可能性是存在的……" |
| 混混 | "你懂不懂啊，别给我整那些虚的。" |
| 医生 | "根据临床经验，这种情况建议手术处理。" |
| 网红 | "家人们，谁懂啊，这个真的绝绝子！" |

---

### 维度2：句长 (Sentence Length)

**规律**：
- 急躁/愤怒 → 短句
- 啰嗦/焦虑 → 长句
- 自信 → 简短有力
- 不确定 → 吞吞吐吐

**示例对比**：

| 角色 | 句长特征 |
|------|----------|
| 急躁型 | "你闭嘴。" "滚。" "别说了。" |
| 啰嗦型 | "其实我觉得吧，你这个事也不能完全怪你，因为这里面有很多因素是……" |
| 思考型 | "让我想想……嗯，这件事，问题可能出在……" |
| 自信型 | "我知道该怎么做。" |

---

### 维度3：节奏 (Rhythm)

**要素**：
- 停顿习惯
- 说话速度
- 标点使用（破折号、省略号）
- 重复词

**示例对比**：

| 角色 | 节奏特征 |
|------|----------|
| 犹豫者 | "我……我觉得……可能……要不要……" |
| 干脆型 | "去。现在。马上。" |
| 戏剧型 | "从那一天起——一切都变了。" |
| 思考型 | "嗯……等一下……让我想想……" |

---

### 维度4：态度 (Attitude)

**态度类型**：
- 讽刺 vs 真诚
- 攻击 vs 防御
- 居高临下 vs 卑微
- 玩世不恭 vs 认真

**示例对比**：

| 角色 | 态度 |
|------|------|
| 讽刺型 | "哦，是吗？太棒了，你真是个天才。" |
| 真诚型 | "是的，我也是这么想的。" |
| 防御型 | "我什么时候说过那种话？你别乱讲。" |
| 玩世不恭 | "人生嘛，不就是这么回事，认真你就输了。" |

## 实战练习

### 场景：被问"你爱不爱我"

| 角色 | 台词 |
|------|------|
| 直接型 | "爱。" |
| 回避型 | "你今天怎么问这种问题？" |
| 反问型 | "你觉得呢？" |
| 攻击型 | "你都怀疑我爱不爱了，我们还过什么过？" |
| 温柔型 | "傻瓜，我做的每一件事不都在告诉你吗？" |
| 傲娇型 | "……哼。" |

---

## 组合示例

### 角色A：老江湖商人

- 用词：商业术语、金句
- 句长：中长句，偶尔短句
- 节奏：慢条斯理，胸有成竹
- 态度：居高临下，笑里藏刀

> "张总啊，我们都是做生意的人，道理你比我懂。这笔账……你说是吧？"

### 角色B：刚毕业的女助理

- 用词：学生气、礼貌用语多
- 句长：中句为主
- 节奏：紧张、偶尔卡壳
- 态度：谦卑、讨好

> "那个……李总，这个方案我改了三版了，您看要不要……我再改一版？"

### 角色C：黑帮小弟

- 用词：江湖黑话、俗语
- 句长：短句
- 节奏：快、偶尔爆发
- 态度：硬气、护主

> "哥，那小子不识相，要不要我收拾他？"

## 自检清单

写完一段群戏后：

```
1. 遮住角色名，只看台词
2. 能猜出每句是谁说的吗？
3. 如果不能——这个角色的声音需要加强
```

## 快速技巧

**给每个角色设定一个口头禅**：

| 角色 | 口头禅 |
|------|--------|
| 理性型 | "从逻辑上说……" |
| 感性型 | "但我觉得……" |
| 痞气型 | "你懂的。" |
| 装逼型 | "说实话……" |
