# 台词→完整剧本5步法

> 从一段对白素材扩展成完整场景剧本的方法

---

## 流程总览

```
Step 1: 分析原始台词（谁/对谁/要什么/真实想法）
Step 2: 补充场景要素（地点/时间/环境/动作）
Step 3: 加入潜台词层（表面/内在分离）
Step 4: 结构化分场（INT./EXT. 格式）
Step 5: Fountain格式输出
```

---

## Step 1: 分析原始台词

**拿到台词后，问四个问题**：

| 问题 | 含义 |
|------|------|
| **谁在说？** | 角色身份、性格 |
| **对谁说？** | 对象关系、双方立场 |
| **想要什么？** | 表层意图 |
| **真实想法是什么？** | 潜台词 |

**示例**：

```
原始台词：
"你什么时候有空？我们很久没见了。"

分析：
谁在说？→ 一个想复合的前女友
对谁说？→ 分手后的前男友
想要什么？→ 想见他
真实想法→ 我还爱你，我想复合
```

---

## Step 2: 补充场景要素

**场景信息清单**：

```
【场景】INT. 星巴克 - 日
【环境】暖黄灯光，咖啡机声，窗外人流
【动作】她把手机放在桌上，手指敲打杯壁
【情绪】紧张、期待、一点点害怕
```

**示例完整场景**：

```
【场景】INT. 星巴克 - 日

暖黄色灯光，咖啡机嗡嗡作响。她坐在角落，
手指无意识地敲打着纸杯。

她拿起手机，又放下，深吸一口气。
终于按下了发送键。

（她的台词）
"你什么时候有空？我们很久没见了。"
```

---

## Step 3: 加入潜台词层

**三栏对照法**：

| 表面台词 | 潜台词 | 动作暗示 |
|----------|--------|----------|
| "你什么时候有空？" | 我想见你 | 她低头看手机 |
| "我们很久没见了。" | 我想你 | 手指敲打杯子 |
| "随便你，不来也行。" | 你必须来 | 把手机推远 |

**示例扩展**：

```
她：你在干嘛？
她：（低头搅动咖啡，不看他的眼睛）
她：就是问问。
她：（潜台词：我不想显得太主动）

他：（沉默）
他：我最近挺忙的。
他：（潜台词：我不想见你）
他：你有什么事吗？
```

---

## Step 4: 结构化分场

**标准格式**：

```fountain
INT./EXT. 地点 - 时间

[环境描写段落]

[角色动作描写]

角色名
（动作/情绪提示）
台词内容。

[角色反应描写]
```

**场景类型**：

| 格式 | 含义 | 示例 |
|------|------|------|
| INT. | 内景（室内） | INT. 咖啡馆 - 夜 |
| EXT. | 外景（室外） | EXT. 街道 - 日 |
| DAY/NIGHT/DAWN/DUSK | 时间 | INT. 办公室 - 夜 |

---

## Step 5: Fountain格式输出

**Fountain语法**：

```fountain
INT. 咖啡馆 - 日

暖黄色灯光照亮整个空间。窗外人流匆匆。
她坐在角落，面前放着一杯已经凉了的拿铁。

她看了一眼手机，又把它翻过去扣在桌上。
深吸一口气。

她
（自言自语）
"三年了，他还是没回我消息。"

门铃响起。她抬头，心跳漏了一拍。

是他。
```

## 快速模板

### 单人独白场景

```fountain
INT. 地点 - 时间

[环境描写] [角色出场方式]

角色名
（情绪/动作提示）
[独白内容]
```

### 双人对话场景

```fountain
INT. 地点 - 时间

[环境描写] [两角色出场]

角色A
台词。

角色B
（反应）
回应。

角色A
（变化）
[推进剧情的台词或动作]
```

### 群戏场景

```fountain
INT. 地点 - 时间

[环境描写] [众人在场]

角色A
（对角色B）
台词。

[旁观角色C的反应]

角色B
回应。
```

## 常见问题

### ❌ 台词太直白
- 解决：加潜台词层

### ❌ 所有人说话一样
- 解决：用四维度区分（用词/句长/节奏/态度）

### ❌ 台词太长
- 解决：拆成多个短句，加动作间隔

### ❌ 没有推动剧情
- 解决：每句台词必须至少满足一个功能

## 示例：完整改编流程

### 原始素材

```
女："你变了。"
男："我怎么变了？"
女："你以前不是这样的。"
```

### Step 1 分析

```
谁在说？→ 失望的妻子
对谁说？→ 变得冷漠的丈夫
想要什么？→ 让他变回以前那样
真实想法→ 我害怕失去你
```

### Step 2 补充场景

```
场景：深夜卧室
环境：月光透过窗帘，两人背对背躺在床上
动作：她转身看他，他假装睡着
```

### Step 3 加潜台词

```
她：（轻声）你变了。
她：（潜台词：我很害怕你会离开我）

他：（沉默）
他：（潜台词：我知道，但我不知道该说什么）

她：你以前不是这样的。
她：（潜台词：那个爱我的你去哪了？）
```

### Step 4 Fountain格式

```fountain
INT. 卧室 - 深夜

月光透过窗帘洒在床上。两人背对背躺着。

她转过身，看着他的背影。

她
（轻声）
你变了。

他没回答。他的呼吸很均匀，但她在黑暗中
看到他肩膀微微绷紧——他没睡着。

她
（更轻）
你以前不是这样的。

他
（沉默了一会儿）
……人都会变。

她把脸埋进枕头里。泪水无声地滑落。
```
