# 小说→AI短剧7步法

> 网络小说改编竖屏短剧的标准化流程

---

## 流程总览

```
Step 1: 梳理主线（核心故事线）
Step 2: 提取核心冲突（剧的灵魂）
Step 3: 确定主角动机（他想要什么）
Step 4: 设计反转点（每20集一个大转折）
Step 5: 压缩人物线（保留核心角色）
Step 6: 拆分集数（每集一个小钩子）
Step 7: AI辅助生成剧本
```

---

## Step 1: 梳理主线

**任务**：从10万字小说中提取1条核心故事线

**方法**：

```
问自己三个问题：
1. 这个故事讲的是谁？（主角）
2. 他一开始处于什么状态？（日常）
3. 最后他变成了什么？（结局）

用一句话概括：
"一个[身份]的[某人]，
从[初始状态]，
经历[核心事件]，
最终[成长/成功/失败]"
```

**示例**：

```
小说：《总裁的替身前妻》
提炼：
"一个被丈夫抛弃的单亲妈妈，
从社会底层重新开始，
经历职场与感情的磨难，
最终实现自我价值并收获真爱"
```

---

## Step 2: 提取核心冲突

**任务**：找到故事的核心矛盾

**冲突类型**：

| 冲突类型 | 示例 |
|----------|------|
| 人 vs 人 | 原配 vs 小三、情敌 |
| 人 vs 环境 | 职场竞争、家庭压力 |
| 人 vs 内心 | 失忆、身份认同 |
| 人 vs 命运 | 绝症、遗传诅咒 |

**保留原则**：一部剧只围绕**一个核心冲突**，其他冲突辅助

**示例**：
```
核心冲突：她发现丈夫还活着，但他假装不认识她
辅助冲突：情敌试图抢走她的位置
```

---

## Step 3: 确定主角动机

**任务**：明确主角每一步行动的原因

**动机层次**：

```
表层动机：他/她想要什么（外在目标）
深层动机：他/她内心缺失什么（内在成长）
```

**示例**：

| 角色 | 表层动机 | 深层动机 |
|------|----------|----------|
| 女主角 | 复仇 | 被爱 |
| 男主角 | 找回记忆 | 找到自我认同 |
| 女二 | 抢走男主 | 被认可 |

---

## Step 4: 设计反转点

**任务**：规划80集的反转节奏

**反转密度**：

```
每3集   → 一个小冲突/误会
每10集  → 关系升级或降级
每20集  → 重大真相揭露
每40集  → 身份/关系根本性改变
第80集  → 终极高潮+收尾
```

**反转设计模板**：

```
第20集反转：发现身份
"你妈妈不是你的亲生母亲"
第40集反转：发现阴谋
"这一切都是他设计的"
第60集反转：最低谷
"孩子没有了"
```

---

## Step 5: 压缩人物线

**任务**：将小说中的大量人物精简到可拍的规模

**人物数量标准**：

```
核心角色：2-3人（主角+对手+盟友）
重要配角：4-6人（家人/朋友/情敌）
背景角色：若干（不需要名字）
```

**保留原则**：

| 保留 | 删除 |
|------|------|
| 推动剧情的角色 | 只出现一次的角色 |
| 有成长弧线的角色 | 功能重复的角色 |
| 代表某种类型的角色 | 过于复杂/敏感的角色 |

---

## Step 6: 拆分集数

**任务**：将80集内容分配到每集

**单集结构**（2-3分钟/集）：

```
开场（0-15秒）：建立本集情境
发展（60-90秒）：主角行动/遭遇障碍
结尾（15-30秒）：留下钩子，吸引继续看
```

**集束结尾公式**：

```
"突然[事件A]发生，
导致[角色]陷入[困境]，
而[另一个角色]的反应是……"
```

**示例**：
```
第15集结尾：
她收到一条短信，上面写着：
"你的女儿在我手里。"
而此刻，她正要参加前夫的婚礼。
```

---

## Step 7: AI辅助生成剧本

**任务**：用AI工具辅助生成具体剧本内容

**推荐工具组合**：

| 用途 | 工具 |
|------|------|
| 故事结构 | ChatGPT / Claude |
| 对白生成 | Claude (角色一致性最强) |
| 分镜脚本 | 自有模板 |
| 提示词 | Seedance / Runway |

**AI辅助流程**：

```
1. 输入：故事大纲 + 人物设定 + 集数规划
2. AI生成：每集详细场景描述
3. 人工审核：调整不符合角色的台词
4. AI补充：具体对白
5. 人工打磨：加潜台词、调整节奏
```

**提示词模板**：

```
你是资深短剧编剧。
请为以下故事写第X集剧本：

故事背景：[一句话概括]
主角设定：[性格/动机/说话风格]
配角设定：[同上]
本集内容：[本集要发生的事]
上集结尾：[上一集的钩子]

要求：
- 每句台词要体现角色声音
- 加入潜台词
- 结尾留钩子
- 格式：[内景/外景] [地点] - [时间]
```

---

## 自检清单

完成改编后检查：

```
1. 核心冲突清晰吗？
2. 主角动机合理吗？
3. 反转密度够吗？（不能太平）
4. 人物精简到可拍规模了吗？
5. 每集结尾有钩子吗？
6. 台词符合角色设定吗？
```

---

## 案例：小说80集改编示例

```
原小说：50万字宫斗文
核心冲突：皇后被陷害失去孩子，重新夺权
主角动机：复仇+保护家族
反转规划：
  - 20集：发现真凶是贵妃
  - 40集：发现皇帝知情
  - 60集：被打入冷宫
  - 80集：翻盘+新危机

精简人物：保留皇帝、贵妃、太监、女官4人
```

---

_适合改编类型：都市言情、宫斗、古装、职场、虐恋_
