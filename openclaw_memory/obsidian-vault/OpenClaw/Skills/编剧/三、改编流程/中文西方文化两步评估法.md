# 中文→西方文化两步评估法

> 评估中文短剧在西方市场改编可行性的标准化方法

---

## 背景说明

中文短剧的核心套路（替嫁、失忆、身份反转等）源自中文网络文学，在西方市场需要**文化翻译**，而非简单直译。

---

## 第一步：文化冲突扫描

**任务**：识别原作品中需要在西方版本中重新设计的元素

### 评估维度

| 维度 | 中文版本 | 西方版本 | 冲突等级 |
|------|----------|----------|----------|
| 家庭关系 | 家族责任、门第观念 | 个人自由、独立 |
| 爱情观 | 命中注定、门当户对 | 自由恋爱、个人选择 |
| 金钱观 | 财富=成功、彩礼嫁妆 | 白手起家、个人财富观 |
| 社会等级 | 权贵、平民、豪门 | 阶层流动性更强 |
| 性别角色 | 传统分工 | 更平等的性别观 |
| 婚姻制度 | 包办婚姻、先婚后爱 | 约会文化、离婚率高 |
| "面子"文化 | 社会评价很重要 | 个人感受更重要 |

---

### 冲突识别清单

逐集检查以下元素：

```
□ 家族压力/包办婚姻元素
□ 门第/阶层差异（豪门vs穷小子）
□ 传统节日习俗（春节、端午等）
□ 中式称呼体系（岳父岳母、公婆）
□ 中式食物/饮食习惯
□ "缘分/命运"概念
□ "面子"概念
□ 中式职场惯例
□ 中国特有职业（太监、宫女等历史设定）
□ 政治/社会敏感话题
```

---

### 冲突等级分类

| 等级 | 含义 | 处理方式 |
|------|------|----------|
| 🟢 低冲突 | 文化差异自然存在 | 保留，西方观众可理解 |
| 🟡 中冲突 | 需要解释或本地化 | 替换为西方等价物 |
| 🔴 高冲突 | 完全不可通约 | 删除或彻底重写 |

**示例**：

| 元素 | 冲突等级 | 处理方式 |
|------|----------|----------|
| 先婚后爱 | 🟡 中 | 改为"契约关系/假男友" |
| 替嫁 | 🟡 中 | 改为"替身参加活动" |
| 失忆 | 🟢 低 | 直接保留 |
| 身份反转（真假千金）| 🟡 中 | 改为"遗产继承争议" |
| 家族企业争夺 | 🟢 低 | 直接保留 |
| "门当户对" | 🔴 高 | 删除，改用"价值观差异" |

## 第二步：文化适配设计

**任务**：为高/中冲突元素设计西方版本的替代方案

### 常用替代框架

#### 家庭压力 → 个人成长压力

| 中文版 | 西方版 |
|--------|--------|
| 父母逼婚 | 事业与爱情的选择 |
| 家族企业继承 | 创业梦想vs稳定工作 |
| 门第观念 | 贫富差距/阶层问题 |
| 传宗接代 | 生子/领养压力 |

#### 豪门设定 → 西方等价

| 中文版 | 西方版 |
|--------|--------|
| 霸道总裁 | 科技新贵/家族企业继承人 |
| 富二代 | 继承家族企业的"old money" |
| 穷小子逆袭 | "self-made"成功故事 |
| 豪门恩怨 | 比弗利山庄/华尔街精英圈 |

#### 称呼体系本地化

| 中文版 | 西方版 |
|--------|--------|
| 岳父/岳母 | 直接叫名字（更平等）|
| 公婆 | 直接叫名字 |
| 少爷/小姐 | 有名字的昵称 |
| 老爷/夫人 | CEO/Partner等职位称呼 |

## 两步评估输出模板

### 逐集评估表

```
集数：第X集
核心冲突：[描述]
文化元素：[识别出的文化特定元素]
冲突等级：[🟢/🟡/🔴]
适配方案：[西方版本的替代设计]
```

### 示例评估

```
集数：第5集
核心冲突：女主被迫代替姐姐嫁给男主
文化元素：包办婚姻、替嫁
冲突等级：🟡 中
适配方案：
  - 删除"父母包办"背景
  - 改为：女主为帮助家族，假扮姐姐参加商业联姻
  - 后续发展基于"谎言"而非"替嫁"
```

## 常见问题

### ❌ 保留中式设定但不解释
- 西方观众无法理解"门第"概念

### ❌ 直接翻译中式梗
- "备胎"直接翻成"spare tire"，完全失去含义

### ✅ 翻译文化，不翻译字面
- "门当户对" → "right kind of family background" + 解释

### 案例：替嫁情节

| 维度 | 中文版 | 西方版 |
|------|--------|--------|
| 背景 | 父母包办婚姻 | 家族企业联姻 |
| 动机 | 家族利益 | 生意合约 |
| 冲突 | 被迫嫁给不喜欢的人 | 假扮身份被发现 |
| 解决 | 日久生情 | 价值观碰撞后认可 |
