## 四、核心总结

### 与特斯拉关联度
```
联创电子（独家供应）＞德赛西威（核心代工）＞韦尔股份（芯片配套）
```

### 业绩稳定性
```
韦尔股份 > 德赛西威 > 联创电子
```

### 智能驾驶业务影响
- 德赛西威、韦尔股份：业绩兑现度高
- 联创电子：业务占比高但盈利性较弱
