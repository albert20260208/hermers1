## 如何使用

### 模式1：理论问答（当主人问"巴菲特对XX怎么看"时）

```yaml
操作：
  1. 加载 theory/knowledge/search-index.json
  2. 关键词匹配，找到相关知识点
  3. 从对应知识点文件读取详细内容
  4. 原文引用 + 核心观点摘要 + 联系实战

示例：
  问："巴菲特怎么看高负债公司？"
  答：搜索 knowledge/ → 找到相关知识点
  → buffett_1990_高杠杆的致命诱惑.txt
  → 核心观点：巴菲特认为"合理的负债比例 + 稳定的现金流"才是安全
  → 联系实战：所以选股时要求资产负债率 < 40%
```

### 模式2：选股实战（当主人说"帮我筛选/跟踪"时）

```yaml
操作：
  1. 加载 practice/screening_criteria.md — 获得量化指标
  2. 从实时行情获取 PE/PB/股息率/ROE 数据
  3. 分三档分类输出（纯烟蒂/烟蒂+成长/优质成长）
  4. 对照理论依据（通过 bridge/mapping.md 溯源）
  5. 生成买卖建议（通过 bridge/decision_logic.md）
```

### 模式3：理论→实战映射（当主人问"为什么这个标准很重要"时）

```yaml
操作：
  1. 从 bridge/mapping.md 找到该标准的理论来源
  2. 在 theory/knowledge/ 中找到对应知识点
  3. 引用巴菲特/芒格/段永平原话支撑该标准
  4. 说明该标准在 A 股市场的应用考量
```

## 核心思想体系

### 三大投资哲学（从理论中提炼）
| 哲学 | 核心 | 对应的实战标准 |
|------|------|--------------|
| **买股票就是买企业** | 关注企业本身而非股价波动 | ROE > 15%，毛利率 > 30% |
| **安全边际** | 好价格比好企业更重要 | PB < 1.2，PE < 12，股息率 > 4% |
| **能力圈** | 只投资理解的企业 | 业务简单易理解，行业龙头或前三 |

### 八大知识点分类（theory/knowledge/）
| 分类 | 说明 | 关键知识点数 |
|------|------|:-----------:|
| 投资原则 | 安全边际、能力圈、不情绪化 | ~70 |
| 估值方法 | 内在价值、自由现金流、ROE | ~60 |
| 商业分析 | 护城河、管理层、经济特性 | ~85 |
| 市场与心理 | 市场先生、贪婪恐惧 | ~50 |

### 三道分类门（从实战中提炼）
| 门类 | 筛选条件 | 定位 |
|------|---------|------|
| 🟡 **纯烟蒂** | PB<1.2, PE<12, 股息率>5%, 负债率<40% | 理财替代+下行保护 |
| 🟢 **烟蒂+成长** | PE 10~15, 股息率4~5%, 增长率10~16% | 平衡收益+安全 |
| 🔴 **优质成长** | ROE>20%, 毛利率>35%, 增长率>15% | 长期持有+穿越周期 |
| ⚪ **B级观察** | 有亮点但有瑕疵，估值合理 | 备选池持续跟踪 |

---

### 五条操作原则（来自原知识体系）

1. **分散研究** — 同时覆盖多只标的对比分析，不押注单方向
2. **双重过滤** — 优先选择同时满足烟蒂标准和价值投资标准的公司
3. **高股息优先** — 利率下行环境下，高股息是硬安全边际
4. **长期跟踪** — 建议拉长到3年以上观察价值变化
5. **定期复盘** — 每月/每季重新审视基本面和估值变化

---

### 快速判断口诀

```
烟蒂看：低PB×低PE×高股息×低负债
成长看：高ROE×高毛利×稳增长×强现金
双重满足→最佳标的
```

## 六大分析维度（实战+理论结合）

| 维度 | 实战操作 | 理论依据 |
|------|---------|---------|
| **业务分析** | 收入结构、客户集中度、业务单一性 | 能力圈→只投理解的业务 |
| **财务护城河** | ROE杜邦分解、毛利率稳定性、净现比 | 护城河→持久竞争优势 |
| **管理层** | 专注度、分红习惯、薪酬合理性 | 优秀管理层→好企业的基因 |
| **行业趋势** | 存量 vs 增量、结构升级、竞争格局 | 宏观经济→行业生命周期 |
| **估值** | PE/PB历史分位、股息率、破净状态 | 安全边际→低估才是机会 |
| **现金流** | 经营现金流 vs 净利润、分红能力 | 所有者盈余→真金白银 |
