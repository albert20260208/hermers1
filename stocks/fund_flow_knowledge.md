## 二、四状态分析法（实战核心框架）

### 2✕2 状态矩阵

将「主力资金」正负与「散户资金」正负组合为四种状态：

```
                 散户流入(+)
                     │
   状态④ ⚠️         │    状态①
  主力流出           │    主力流入
  散户流入           │    散户流入
  【散户接盘】       │    【普涨行情】
                     │
─────────────────────┼───────────────────── 主力
                     │
   状态③             │    状态② ✅
  主力流出           │    主力流入
  散户流出           │    散户流出
  【全面撤退】       │    【主力吸筹】
                     │
                 散户流出(-)
```

### 各状态详解

| 状态 | 主力 | 散户 | 市场含义 | 操作建议 | 用词 |
|------|------|------|---------|---------|------|
| **① 普涨** | + | + | 牛市特征，所有人看好 | 持有，但注意估值 | 中性偏正 |
| **② 主力吸筹** ✅ | + | - | ⭐**最佳买点信号** — 主力在低位买入，散户恐慌割肉 | **买入或加仓** | 积极看多 |
| **③ 全面撤退** | - | - | 集体不看好，资金出逃 | 观望，勿抄底 | 强烈看空 |
| **④ 主力出货** ⚠️ | - | + | ⚠️**最危险信号** — 主力派发给散户 | **减仓或清仓** | 强烈看空 |

### 实战应用场景
1. **状态②** → 股价低位震荡，主力偷偷建仓，散户被洗出去后 → 后续拉升概率大
2. **状态④** → 股价高位横盘，主力边拉边卖，散户追涨接盘 → 即将见顶
3. **状态①→④**: 上涨过程中从①转为④ → 顶部预警，准备减仓
4. **状态③→②**: 下跌过程中从③转为② → 底部确认，可以建仓

## 三、背离信号（最高实战价值）

### 顶背离（卖出信号）
```
价格: 创出新高 (Higher High)
主力资金净流入: 未创新高或持续减少
→ 主力借拉高出货，上涨动能衰竭
→ **卖出或减仓**
```

### 底背离（买入信号）
```
价格: 创出新低 (Lower Low)
主力资金净流入: 未创新低或持续增加
→ 主力在低位吸筹，下跌动能衰竭
→ **买入或加仓**
```

### 具体判定标准

**顶背离判定:**
```python
def is_top_divergence(price_series, fund_flow_series):
    # 最近N日 vs 之前N日比较
    recent_high = price_series[-3:].max()
    prev_high = price_series[-6:-3].max()
    recent_flow = fund_flow_series[-3:].sum()
    prev_flow = fund_flow_series[-6:-3].sum()

    if recent_high > prev_high and recent_flow < prev_flow:
        return True  # 价格新高但资金流减少 → 顶背离
    return False
```

**底背离判定:**
```python
def is_bottom_divergence(price_series, fund_flow_series):
    recent_low = price_series[-3:].min()
    prev_low = price_series[-6:-3].min()
    recent_flow = fund_flow_series[-3:].sum()
    prev_flow = fund_flow_series[-6:-3].sum()

    if recent_low < prev_low and recent_flow > prev_flow:
        return True  # 价格新低但资金流增加 → 底背离
    return False
```

### 背离的时间尺度
| 级别 | 参考K线 | 效力 | 操作周期 |
|------|---------|------|---------|
| 短线背离 | 15/30分钟 | 较弱 | 1-2天 |
| 中线背离 | 日线 | ⭐⭐⭐ | 1-2周 |
| 长线背离 | 周线 | ⭐⭐⭐⭐⭐ | 1-3月 |

## 四、NIR_MOD 修正因子（开源金融工程成果）

### 核心问题
资金流与涨跌幅天然正相关（股票涨了自然买入多），原始资金流因子有偏。

### 修正方法
```
NIR = 个股净流入率 - 行业平均净流入率
NIR_MOD = 对NIR进行截面回归，剥离涨跌幅影响
```

### 计算公式
```python
import statsmodels.api as sm

def calc_nir_mod(fund_flow_df, return_df):
    """
    fund_flow_df: DataFrame (个股权重净流入率)
    return_df: DataFrame (个股涨跌幅)
    """
    # 截面回归: NIR = α + β×return + ε
    X = sm.add_constant(return_df)
    for each_date:
        y = fund_flow_df.loc[each_date]
        model = sm.OLS(y, X.loc[each_date]).fit()
        residual = y - model.predict(X.loc[each_date])
        # NIR_MOD = 回归残差（剥离了涨跌幅影响的净流入率）
    return residual_df
```

### 效果
| 因子 | 多头年化 | IR | 夏普 |
|------|---------|-----|------|
| 原始NIR | 12.3% | 2.63 | 1.45 |
| **NIR_MOD** | **18.7%** | **4.76** | **2.31** |

> IR提升约82%，说明剥离涨跌幅干扰后信号质量大幅提升

## 五、广义主力因子（CNIR — 最佳实践）

### 核心发现（开源证券研报）
最优的资金分档阈值不是API默认的20万元，而是 **2万元**。

### CNIR因子构建
```python
def calc_cnir(tick_data):
    """
    基于逐笔成交数据，以2万元为阈值
    """
    # 单笔>=2万元 → 广义主力
    # 单笔<2万元 → 广义散户
    broad_main = tick_data[tick_data.amount >= 20000]
    broad_retail = tick_data[tick_data.amount < 20000]

    cnir = broad_main['amount_sum'] - broad_retail['amount_sum']
    cnir_ratio = cnir / tick_data['amount_sum'].sum()
    return cnir_ratio
```

### 效果
| 因子 | 多头年化 | IR | 最大回撤 |
|------|---------|-----|---------|
| 传统主力因子 | 15.2% | 3.12 | 18.5% |
| **CNIR因子** | **27.86%** | **4.91** | **12.3%** |

## 七、尾盘资金操纵识别

### 尾盘突袭特征
| 特征 | 正常情况 | 操纵迹象 |
|------|---------|---------|
| 时间 | 分散全天 | 集中在14:55-15:00最后5分钟 |
| 单笔量 | 平均分布 | 最后几分钟突然超大单 |
| 价格影响 | 平稳 | 尾盘急剧拉升/打压 |
| 次日表现 | 延续趋势 | 经常反转（高开低走/低开高走） |

### 检测逻辑
```python
def detect_manipulation(tick_last_5min, tick_all_day):
    """检测尾盘资金操纵"""
    last_5min_volume = sum(t.last_5min_volume)
    all_day_volume = sum(t.all_day_volume)

    ratio = last_5min_volume / all_day_volume

    if ratio > 0.10:  # 最后5分钟成交超过全天10%
        return '⚠️ 尾盘异动', ratio
    return '正常', ratio
```

### 处理建议
- 尾盘突袭拉升 → 第二天早盘高开卖出（大概率回落）
- 尾盘突袭砸盘 → 如果基本面OK，可能是洗盘，第二天低开可买入

## 八、板块/行业资金联动

### 核心逻辑
"个股的资金流，必须放在板块背景下看才有意义"

### 板块维度分析

```
个股主力净流入 + 板块主力净流入 → 确定性最高 ✅
个股主力净流入 + 板块主力净流出 → 可能是补涨/资金没处去 ❌
个股主力净流出 + 板块主力净流入 → 该股有问题，资金转移到板块内其它股 ⚠️
板块主力净流入 + 该板块指数涨 → 健康上涨 ✅
板块主力净流入 + 该板块指数跌 → 即将爆发的信号 ✅（主力入场还未拉升）
```

### 行业轮动检测
```python
def detect_sector_rotation(all_sectors_fund_flow):
    """检测行业资金轮动"""
    # 计算每个行业近5日累计主力净流入排名
    sectors['5d_main_flow'] = sectors.groupby('sector')['main_net'].rolling(5).sum()

    # 最近5日 vs 前5日排名变化
    sectors['rank_current'] = sectors['5d_main_flow'].rank(ascending=False)
    sectors['rank_prev'] = sectors['5d_main_flow_prev'].rank(ascending=False)

    # 排名上升最快的 → 资金新流入方向
    sectors['rank_change'] = sectors['rank_prev'] - sectors['rank_current']
    hot_sectors = sectors[sectors['rank_change'] > 0].sort_values('rank_change', ascending=False)

    return hot_sectors
```

## 十、实战数据陷阱

### 1. 单日逆势（必须看累计）
- 某日主力净流出，但当日大盘暴跌5% → 个股可能实际抗跌
- 某日主力净流入，但大盘暴涨 → 可能只是跟涨

### 2. 大单拆分（Level-2 vs 普通行情）
- 机构会把500万大单拆成50笔10万，从超大单降为大单
- 超级资金净流入为负，不代表真正大资金在撤退

### 3. 对倒交易
- 自买自卖制造资金活跃假象
- 具体特征：卖单和买单几乎同时出现，数量一致
- 检测方法：逐笔成交，匹配买卖方向

### 4. 解禁/配股影响
- 解禁后大股东减持 → 即使股价上涨，超大单也可能持续流出
- 需要结合公告信息判断
