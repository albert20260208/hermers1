# 台词改编剧本技巧

> 从对白/台词出发，改编成完整剧本的方法论

---

## 一、核心理念：「先建结构，后写台词」

**正确顺序**：
```
1. 人物弧线（角色成长轨迹）
2. 场景结构（每场戏的目的）
3. 故事节拍（关键转折点）
4. 最后才写台词
```
**原因**：知道角色在每个场景中**想要什么**，台词自然流出。

---

## 二、台词的三大功能

| 功能 | 说明 | 示例 |
|------|------|------|
| **信息（Exposition）** | 传递信息给观众/其他角色 | "三年前那场火灾后，他就再没说过话" |
| **性格（Characterization）** | 展现角色性格和欲望 | 粗人说粗话，文人说文话 |
| **行动（Action）** | 推动决策，揭示下一步 | "我决定了，明天就走" |

**检验标准**：每句台词必须至少满足一个功能，否则删掉。

---

## 三、台词→剧本实操流程

### Step 1: 分析原始台词

拿到台词后，先问：
- 谁在说？（角色身份）
- 对谁说？（对象关系）
- 想要什么？（意图/欲望）
- 真实想法是什么？（潜台词）

### Step 2: 补充场景要素

```
【场景】INT. 理发店 - 夜
【环境】暖黄灯光，镜子反射，吹风机声

【动作】王琴琴站在镜前，拿起口红描唇

【台词】
王琴琴：（看着镜中的自己，嘴角微扬）
    "今晚，该轮到我了。"

【潜台词】她等这一刻很久了，准备出手
```

### Step 3: 加入潜台词层

| 表面台词 | 潜台词 |
|----------|--------|
| "你最近还好吗？" | 我知道你出事了 |
| "随便你" | 我很在意但不想说 |
| "我没事" | 我有事但不想让你担心 |

### Step 4: 结构化分场

```
场景头格式：INT./EXT. 地点 - 时间

INT. = 内景
EXT. = 外景
DAY/NIGHT/DAWN/DUSK = 时间
```

### Step 5: Fountain格式输出

```fountain
INT. 理发店 - 夜

暖黄色灯光照亮整个空间。镜子前，王琴琴正在描唇。

王琴琴
（看着镜中的自己）
今晚，该轮到我了。

她放下口红，嘴角勾起一抹危险的笑。
```

## 四、角色声音区分技巧

### 每个角色要有独特"声音"

| 维度 | 区分方式 |
|------|---------|
| **用词** | 文化程度、职业术语、口头禅 |
| **句长** | 急躁角色短句、啰嗦角色长句 |
| **节奏** | 有人快言快语、有人慢条斯理 |
| **态度** | 讽刺、真诚、防御、攻击 |

### 测试方法

遮住角色名，只看台词，能不能猜出是谁说的？
如果猜不出 → 角色声音不够独特。

## 五、塔伦蒂诺台词秘诀

1. **角色驱动**：不按模板写，知道角色是谁、想要什么
2. **允许"闲聊"**：看似无关的对话建立角色关系
3. **台词成为景点**：经典对话本身就是看点
4. **意外转折**：聊着聊着突然变紧张

**经典案例**：《低俗小说》开场餐厅对话 - 5分钟闲聊后突然抢劫

## 七、常见问题

| 问题 | 解决 |
|------|------|
| 台词太直白 | 加潜台词，说A想B |
| 所有人说话一样 | 用词、句长、节奏要区分 |
| 台词太长（超过3行） | 拆成多个短句，加动作间隔 |
| 废话太多（"嗯""啊""那个"） | 除非刻意表现犹豫，否则删掉 |

## 八、快速模板

### 单人独白场景
```fountain
INT. 地点 - 时间

环境描述。角色出场。

角色名
（情绪/动作提示）
台词内容。

动作描述。
```

### 双人对话场景
```fountain
INT. 地点 - 时间

环境描述。角色A和角色B。

角色A
台词。

角色B
（反应）
回应。

角色A的动作或表情变化。
```

### 群戏场景
```fountain
INT. 地点 - 时间

环境描述。众人在场。

角色A
（对角色B）
台词。

角色C在一旁默默观察。

角色B
回应。

气氛变化描述。
```
