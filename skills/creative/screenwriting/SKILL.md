# 短剧编剧技能

## 一、短剧剧本结构（竖屏/短视频）

**黄金3秒法则**：开篇必须有冲突或悬念，不能铺垫

### 常见结构（四段式）

| 阶段 | 集数范围 | 内容 |
|------|----------|------|
| 起 | 1-3集 | 建立人物 + 核心冲突 |
| 承 | 4-20集 | 冲突升级 + 关系推进 |
| 转 | 21-50集 | 身份揭秘 / 重大反转 |
| 合 | 51-80集 | 和解 + 圆满结局 |

### 每集剧本公式

```
上集结尾：钩子（问句/冲突点）
    ↓
本集内容：推进1个核心情节点
    ↓
下集预告：暗示下一个冲突
```

### 爆点密度

- 前3集：必须有强冲突/爆点，不能慢热
- 每5-10集：一个情绪高潮
- 每集结尾：留悬念钩子

## 二、台词核心原则：「先建结构，后写台词」

**正确顺序**：
```
1. 人物弧线（角色成长轨迹）
2. 场景结构（每场戏的目的）
3. 故事节拍（关键转折点）
4. 最后才写台词
```
**原因**：知道角色在每个场景中想要什么，台词自然流出。

### 台词的三大功能

| 功能 | 说明 | 示例 |
|------|------|------|
| **信息（Exposition）** | 传递信息给观众/其他角色 | "三年前那场火灾后，他就再没说过话" |
| **性格（Characterization）** | 展现角色性格和欲望 | 粗人说粗话，文人说文话 |
| **行动（Action）** | 推动决策，揭示下一步 | "我决定了，明天就走" |

**检验标准**：每句台词必须至少满足一个功能，否则删掉。

### 潜台词技巧

| 表面台词 | 潜台词 |
|----------|--------|
| "你最近还好吗？" | 我知道你出事了 |
| "随便你" | 我很在意但不想说 |
| "我没事" | 我有事但不想让你担心 |

**核心**：说A想B，制造层次感。

### 塔伦蒂诺台词秘诀

1. **角色驱动**：不按模板写，知道角色是谁、想要什么
2. **允许"闲聊"**：看似无关的对话建立角色关系
3. **台词成为景点**：经典对话本身就是看点
4. **意外转折**：聊着聊着突然变紧张

**案例**：《低俗小说》开场餐厅对话 - 5分钟闲聊后突然抢劫

### 角色声音区分四维度

| 维度 | 区分方式 |
|------|---------|
| **用词** | 文化程度、职业术语、口头禅 |
| **句长** | 急躁角色短句、啰嗦角色长句 |
| **节奏** | 快言快语 vs 慢条斯理 |
| **态度** | 讽刺、真诚、防御、攻击 |

**测试**：遮住角色名，只看台词能不能猜出是谁说的？猜不出 = 声音不够独特。

### 对白检查清单

- [ ] 每句对白是否有推进剧情？
- [ ] 人物说话方式是否符合性格？
- [ ] 是否有潜台词可以挖掘？
- [ ] 观众能听懂吗（不需额外解释）？

### 常见问题

| 问题 | 解决 |
|------|------|
| 台词太直白 | 加潜台词，说A想B |
| 所有人说话一样 | 用词、句长、节奏要区分 |
| 台词太长（超过3行） | 拆成多个短句，加动作间隔 |
| 废话太多（"嗯""啊""那个"） | 除非刻意表现犹豫，否则删掉 |

## 三、小说改短剧7步法

```
第1步：提取原文概要（30章链接 → 提取核心概要）
    ↓
第2步：建立角色卡（性格/目标/矛盾点/成长弧）
    ↓
第3步：拆解故事线（主线/副线/情感线 + 卡点）
    ↓
第4步：生成详细大纲（起承转合结构）
    ↓
第5步：生成分集大纲（每集1个情节点）
    ↓
第6步：按集写剧本（先大纲后正文）
    ↓
第7步：格式转换（小说语言 → 剧本格式）
```

### 角色卡模板

```markdown
## 角色名

- **身份**：xxx
- **性格**：xxx
- **目标**：xxx（想得到什么）
- **矛盾**：xxx（阻碍目标的是什么）
- **成长弧**：从xxx → 到xxx
- **金句**：xxx
```

## 五、AI辅助编剧工具

| 工具 | 用途 | 特点 |
|------|------|------|
| DeepSeek | 生成分镜脚本、对白 | 速度快，适合初稿 |
| Kimi | 长文本分析小说结构 | 上下文长，适合分析 |
| Claude/GPT | 剧情逻辑梳理、角色分析 | 推理能力强 |
| 搭灯 | AI剧本生成 | 专注短剧 |
| 编剧神器 | 剧本格式辅助 | 模板丰富 |

### AI协作工作流

```
人工：确定故事核心（主题/人物/结局）
    ↓
AI：生成剧情大纲 → 人工审核调整
    ↓
AI：生成分集大纲 → 人工优化
    ↓
AI：按集写剧本 → 人工修改对白
    ↓
人工：最终审核（节奏/逻辑/情绪）
```

### 11人AI编剧室（Story-Systems-Template）

11人AI团队模拟好莱坞编剧室：

| 角色 | 职责 |
|------|------|
| Story Architect | 故事结构（有否决权）|
| Dialogue Writer | 台词，给角色独特声音 |
| Scene Writer | 场景描述和视觉 |
| Continuity Editor | 连续性检查 |
| Script Supervisor | 格式审核（必须通过）|
| Research Specialist | 事实核查 |

**关键**：AI是工具，人是编剧。AI负责初稿，人工负责修改和把关。

## 七、常见问题处理

### Q：原著信息量太大怎么办？
A：聚焦主角+一条主线，其他支线适当删减

### Q：节奏太慢怎么办？
A：每集至少推进1个核心情节点，减少无效对话

### Q：AI生成的对白太水？
A：让人工先梳理角色性格，AI只负责初稿，人工改写

### Q：政策审核风险？
A：避免：血腥暴力、软色情、政治敏感、封建迷信
