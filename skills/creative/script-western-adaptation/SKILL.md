# 中文短剧西方文化改编技能

## 使用场景

给定一个已翻译的中文短剧英文版本，评估其改编质量：
1. 总结已改编的部分属于哪些类型
2. 识别仍不符合西方文化的部分，给出优先级排序

## 改编评估两步法

### 第一步：盘点已有改编

已有改编主要集中在以下类别，读取剧本时同步标记：

| 改编类型 | 示例 | 判断标准 |
|---------|------|---------|
| 称呼语境化 | 陛下→Your Majesty / 老公→babe | 语境对了就行 |
| 中国特色词意译 | 苦檀香→bitter sandalwood / 龙→dragon | 西方有等价概念则保留 |
| 称呼浪漫化 | 哥哥→babe / 少爷→省略 | 浪漫场景不用字面翻译 |
| 制度保留 | 科举→examination system | 需要补充说明 |
| 气味异能设定 | 保留 | 西方奇幻有类似传统 |

### 第二步：识别西方文化冲突

按以下清单逐集扫描，输出优先级排序：

**高优先级（必须改）**
- [ ] 帝王话语体系：朕/旨意/钦此/大赦天下 → decree / by royal decree
- [ ] 王后参政：帝后共治体制西方无对应 → 加体制铺垫或改为授权表达
- [ ] 封号体系首次出现：太子/公主/圣后 → 加英文头衔注释

**中优先级（建议改）**
- [ ] 宫廷职位：宫女/奶妈 → lady-in-waiting / royal attendant / nurse
- [ ] 处罚方式：贬为庶民/赐死 → exile / stripped of title / house arrest
- [ ] 称呼层级：少爷/老爷 → 解释性翻译+注释

**低优先级（可选）**
- [ ] 杀伐果断类台词 → 强化法治/正义包装，弱化残暴感
- [ ] 结局价值观叙事 → 避免帝王暴政联想

## 输出格式

```
## 一、已改编的地方总结

列出主要改编类型，每类附1-2个具体例子。

## 二、仍不符合西方文化的地方

按优先级排序，高/中/低三级，每项说明：
- 问题描述
- 原文（原台词/描述）
- 修改建议

## 三、最需要改的三点

给出最高优先级的三项。
```

## 调用方式

当用户提供一个中文短剧翻译稿并要求：
- "评估改编质量"
- "看看有哪些不符合西方文化的"
- "总结已改编的内容"
- "需要修改的地方"

统一使用本技能的「两步法」和「输出格式」执行。

## 配音工作流（来源：wordsprime.com）

**三种方式区别：**
| 方式 | 说明 |
|------|------|
| **配音 (Dubbing)** | 技术性表演替换，适合情感对话驱动的剧集 |
| **画外音 (Voice-over)** | 保留原音添加叙述层，适合纪录片 |
| **本地化 (Localization)** | 更宽泛策略，包括翻译、文化适配、图形、字幕、合规 |

**配音工作流8步：**
1. 项目简报和市场目标
2. 改编和剧本意图适配（非字面翻译）
3. 术语表和风格规则
4. 选角对齐目标
5. 录音或AI生成
6. 混音和母带处理（优化手机扬声器）
7. 三层质量检查（语言/表演/技术）
8. 交付、元数据和analytics

## 文化差异处理（来源：artlangs.com）

**文化特有词处理：**
| 中国特色词 | 问题 | 建议处理 |
|-----------|------|----------|
| 太极/龙 | 龙在西方代表邪恶，东方代表权力 | 需要解释或替代 |
| 龙王 | 西方观众困惑 | 需文化注释 |

**称呼处理：**
| 中文 | 直译问题 | 正确处理 |
|------|----------|----------|
| 哥哥 | "brother"会让人误解关系 | 根据语境：浪漫伴侣/哥哥 |
| 叔叔/阿姨 | 不能统一翻译 | 根据语境调整 |

**成语/俗语：**
| 中文 | 字面意思 | 真实含义 |
|------|----------|----------|
| 吃醋 | 吃醋 | 嫉妒 |
| 拍马屁 | 拍马屁股 | 阿谀奉承 |

## 配音vs字幕选择

| 方式 | 优点 | 缺点 | 适用市场 |
|------|------|------|----------|
| **配音** | 沉浸感强 | 成本高、周期长 | 美国/英国主力市场 |
| **字幕** | 成本低、保留原音 | 部分观众不爱看 | 东南亚/非英语国家 |
| **AI配音** | 便宜快速 | 质感较差 | 测试/小规模 |
