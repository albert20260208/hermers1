## 📘 **文档核心摘要**
文档重点介绍了 **Python Install Manager**（Python 安装管理器）这一新工具，它负责管理 Python 运行时、提供全局 `python` 和 `py` 命令，并支持虚拟环境隔离。

## 🚀 **执行 Python 命令的几种方式**

### 1. **全局 Python 命令（推荐）**
安装 Python Install Manager 后，可以在**任何终端**中直接使用：
```cmd
python
```
- 启动当前默认版本的 Python 交互式解释器（出现 `>>>` 提示符）
- 退出交互模式：输入 `exit()` 或按 `Ctrl+Z` + `Enter`

### 2. **运行 Python 脚本**
```cmd
python 脚本名.py
```
例如：
```cmd
python hello.py
```

### 3. **使用 `py` 命令管理多版本**
```cmd
py -3.14      # 启动 Python 3.14
py -3.13      # 启动 Python 3.13
py -3         # 启动最新 Python 3.x
py list       # 查看已安装的 Python 版本
```

### 4. **从脚本中调用（Shebang 行）**
在 `.py` 文件开头添加：
```python
#!/usr/bin/env python3
# 或
#!python
```
然后双击脚本文件或在命令行直接输入脚本名（需正确关联）。

### 5. **通过虚拟环境执行**
```cmd
# 创建虚拟环境
python -m venv myenv

# 激活虚拟环境（Windows）
myenv\Scripts\activate.bat    # CMD
myenv\Scripts\Activate.ps1    # PowerShell

# 在虚拟环境中安装包、运行脚本
pip install requests
python myscript.py

# 退出虚拟环境
deactivate
```

## ⚠️ **常见问题与解决**
| 问题 | 解决方法 |
|------|----------|
| `'python' 不是内部或外部命令` | 1. 重新运行 Python Install Manager 安装<br>2. 检查系统 PATH 是否包含 Python 目录 |
| 多个 Python 版本冲突 | 使用 `py -版本号` 指定版本 |
| 脚本双击无反应 | 重新关联 `.py` 文件类型：`assoc .py=Python.File` |
| 权限错误 | 以管理员身份运行终端 |
