### 🐛 根本原因确认
**文件**: `/usr/local/bin/clawmem`（包装脚本）
```bash
# 第65-69行：硬编码GPU端点，导致所有嵌入尝试连接不存在的GPU服务
export CLAWMEM_EMBED_URL="${CLAWMEM_EMBED_URL:-http://localhost:8088}"
export CLAWMEM_LLM_URL="${CLAWMEM_LLM_URL:-http://localhost:8089}"
export CLAWMEM_RERANK_URL="${CLAWMEM_RERANK_URL:-http://localhost:8090}"
```

**导致后果**：
1. **速度灾难**: 0.38文档/分钟 → 15小时完成时间
2. **连接重试**: 每个片段多次连接超时重试
3. **高CPU等待**: ~90% CPU等待远程响应
4. **用户体验**: "无法正常运行"

### ✅ 方案A实施细节
**绕过了问题包装脚本，直接使用Bun运行**：
```bash
# 1. 停止现有服务
pkill -f "bun.*clawmem"

# 2. 启动HTTP服务（纯本地模式）
cd /opt/clawmem && /usr/bin/bun src/clawmem.ts serve &

# 3. 开始快速嵌入
cd /opt/clawmem && /usr/bin/bun src/clawmem.ts embed 2>&1 | tee /tmp/clawmem_embed_fixed.log &
```
