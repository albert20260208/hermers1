# 索引目录

> 存放高频更新的索引文件，便于快速访问和实时更新

---

## 📋 目录用途

### 核心原则
1. **高频更新**：需要频繁修改的文件放在这里
2. **快速访问**：路径简洁，便于 `cat`、`edit` 等操作
3. **实时状态**：反映系统当前状态，而非历史记录

### 与 `journals/` 的区别
| 目录 | 内容类型 | 更新频率 | 时间维度 |
|------|----------|----------|----------|
| **`indexes/`** | 当前状态索引 | 高频（实时） | 现在 |
| **`journals/`** | 历史日志记录 | 低频（每日） | 过去 |

## 🔗 索引使用指南

### 快速访问
```bash
# 查看学习进度
cat memory/indexes/learning_progress.md

# 编辑学习进度
edit memory/indexes/learning_progress.md
```

### 更新规则
1. **实时更新**：学习进度变化时立即更新
2. **版本控制**：每次更新注明版本号和修改原因
3. **路径简洁**：使用相对路径便于其他文件引用

### 与知识系统的关联
```
学习流程：
  计划 (plans) → 进度 (indexes) → 资料 (knowledge) → 技能 (skills)
  
索引作用：
  作为"进度层"，连接计划与资料，记录当前学习状态
```

## 📝 索引文件模板规范

### 通用要求
1. **版本头部**：每个文件开头注明当前版本
2. **更新记录**：记录每次更新的版本、原因、时间
3. **状态清晰**：使用表格或列表展示当前状态
4. **操作指引**：说明如何更新和使用该索引

### 版本命名格式
```
vYYYY-MM-DD-简短描述
示例：v2026-02-21-learning-progress-index-move
```
