## 当前网络限制

系统安全策略阻止了所有直接访问 GitHub 的方式：
- `github.com` → 被拦截
- `api.github.com` → 被拦截
- `gist.github.com` → 被拦截

**错误信息：**
```
Blocked: resolves to private/internal/special-use IP address
```

## 可行方案

### 方案1：使用 web_search（推荐）
虽然不能直接访问，但可以通过搜索获取 GitHub 信息：
- 仓库标题、描述、Star 数
- 文件路径和目录结构
- README 内容片段

### 方案2：配置代理
如果有 HTTP/HTTPS 代理服务器，可以通过代理访问：
```bash
export HTTP_PROXY=http://proxy-server:port
export HTTPS_PROXY=http://proxy-server:port
curl -H "Authorization: token YOUR_TOKEN" \
     https://api.github.com/repos/owner/repo
```

### 方案3：本地克隆
如果能在其他机器上克隆仓库，然后通过文件传输到当前系统。
