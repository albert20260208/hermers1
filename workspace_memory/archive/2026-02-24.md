### 一、因子分类

| 因子类型 | 具体因子 | 选股逻辑 |
|----------|----------|----------|
| **量价因子** | STR凸显性、日内动量、筹码峰、收益波动率 | 技术面信号 |
| **基本面因子** | 股息率TTM、PE、PB、ROE、成长/盈利/营运能力 | 价值/质量筛选 |
| **复合因子** | 多因子加权组合 | 综合打分 |

### 二、因子处理流程
```
原始数据 → 去极值(±3σ) → 标准化(Z-Score) → 中性化(行业/市值) → 可用因子
```

### 三、因子测试方法
1. **IC分析** - 因子值与未来收益的相关性 (IC均值、IR、t值)
2. **分层回测** - 按因子值分10组,看各组收益差异
3. **多空测试** - 做多高分组+做空低分组
4. **共线性分析** - 剔除重复因子,避免冗余

### 四、因子复合方式
| 方法 | 原理 | 适用场景 |
|------|------|----------|
| IC加权 | 按历史IC均值分配权重 | 稳健 |
| 回归加权 | 按因子收益率分配权重 | 动态调整 |
| 排序加权 | 按排名等权/相乘 | 简单有效 |
| PCA分解 | 主成分作为新因子 | 降维去噪 |

### 五、策略构建
- **资产配置**: 等权 / 马科维兹最优 / 最小方差
- **参数优化**: 网格搜索(分层数、调仓周期、目标组)
- **回测指标**: 年化收益、夏普、最大回撤、Calmar
