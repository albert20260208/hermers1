# AI Agent 自我进化学习笔记 (2026-02-28)

## 一、核心概念

### 什么是AI Agent
- **定义**: 能够自主完成复杂任务的AI系统
- **关键能力**: 规划、工具使用、记忆、自我反思

### Agentic Systems vs Workflows
- **Workflows**: 预定义的代码路径，固定流程
- **Agents**: LLM动态指导自己的流程，灵活自主

## 二、构建模块

### 1. 增强型LLM (Augmented LLM)
基础构建块：
- 检索 (Retrieval)
- 工具 (Tools)
- 记忆 (Memory)

### 2. 常见工作流模式

#### Prompt Chaining（提示链）
- 任务分解为固定顺序步骤
- 每个LLM处理前一个输出
- 适用：营销文案→翻译、提纲→写作

#### Routing（路由）
- 分类输入到专门任务
- 分离关注点
- 适用：客服分类、难易分流

#### Parallelization（并行化）
- 同时处理独立子任务
- 投票获得多样化结果
- 适用：并行获取信息、多角度分析

#### Orchestrator-workers（编排器-工作器）
- 动态分配任务
- 中心LLM协调
- 适用：复杂多步骤任务

#### Evaluator-optimizer（评估器-优化器）
- 循环改进直到达标
- 适用：需要高质量输出

## 五、AI Agent Memory 最新研究

### 为什么Memory现在很重要
- LLM是无状态的，每次交互从零开始
- 上下文窗口膨胀的幻象在真实工作负载下崩溃

### 三大设计哲学

| 方案 | 代表 | 特点 |
|------|------|------|
| 向量存储 | Pinecone/Weaviate | 记忆即检索，快但浅表 |
| 摘要压缩 | 滚动摘要 | 记忆即压缩，定期凝练 |
| 图结构 | Zep/Mem0 | 记忆即知识，组织关系 |

### 前沿方案
- **Zep**: 时序知识图谱，长视野准确率+18.5%
- **Mem0**: 结构化摘要，准确率+26%
- **Letta**: 简单文件系统记忆系统

### 贾维斯的启示
- 当前使用：文件系统（NOW.md + memory/）
- 可改进：加入时序关系、知识图谱结构
